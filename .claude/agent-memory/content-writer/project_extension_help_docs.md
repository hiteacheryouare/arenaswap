Wrote all eight articles at `apps/docs/src/content/docs/extension/` (getting-started, watching-multiple-games, switching-and-sensitivity, favorite-teams, standby-stream, settings, demo-mode, troubleshooting) against the shipped popup, background.ts, and packages/core/src/constants.ts at that commit. All eight from the brief were kept; none dropped, none added.

**URL pattern for this collection:** `content.config.ts`'s own comment states one URL per article at `/docs/<section>/<slug>/`, so extension articles cross-link as `/arenaswap/docs/extension/<slug>/`. No index/listing page is implied by the schema; that's presumably Ryan's routing work. Don't invent a `/arenaswap/docs/powerscore/` link without confirming the other agent has actually shipped a slug there — the marketing PowerScore explainer at `/arenaswap/powerscore/` (an existing `pages/powerscore/index.astro`) is the safe, verified link to use instead when a doc needs to point at "what is PowerScore."

**Naming call: "Tab Registry" stays out of user-facing docs.** It's in `AGENTS.md`'s glossary for agents, but grepping locales and the 2.0.0 release notes turns up only one lowercase, incidental "registry" in an engineering bullet — it has never been a name shown to users. The shipped verb is "assign a tab" / "register a tab." Used that everywhere instead of introducing the internal term, on the theory that a help doc should never teach a word the product itself doesn't say. Revisit if a future UI surfaces "Tab Registry" as actual copy.

**Capitalization, overruled by Ryan:** my first pass capitalized feature names as proper nouns in prose ("Demo Mode," matching how the 2.0.0 release notes do it) while keeping literal bolded UI controls in their exact shipped case. Ryan rejected the "Demo Mode" half of that split during the 2026-08-23 revision pass: it is "Demo mode" everywhere now, prose and UI reference alike, matching the shipped `demoMode` locale string exactly. "Standby Stream" was left capitalized and was not corrected, so that half of the split stands. Lesson: don't assume a feature name earns a proper-noun capitalization just because a release note capitalized it once — check whether Ryan has actually ruled on that specific name before applying the pattern to a new one.

**Changelog/code gap found:** the 2.0.0 release notes claim Demo mode ships with "mock playoff series." `packages/core/src/mockGames.ts`'s 15 seeded games (12 leagues, verified by counting `league:` entries) have no `isPostseason` or series field anywhere in the file. Did not carry that claim into demo-mode.md. Consistent with [[feedback_verify_changelog_against_code]] — another instance of the changelog describing a state the shipped code doesn't match.

**Revision pass, 2026-08-23 (same day):** Ryan had a coordinator dispatch a `/technical-writing` + `unslop` pass over all eight files after the initial draft. `disable-model-invocation: true` on the technical-writing skill means it can't be invoked via the Skill tool at all — even a coordinator's explicit ask bounces, and the fallback is `cat`-ing `SKILL.md` and applying it by hand. Findings worth keeping:
- The worst offenders were exactly what the coordinator predicted: long paragraphs in `demo-mode.md` and `troubleshooting.md` carrying 3-4 thoughts in one 30+ word sentence. Splitting them also surfaced a real accuracy bug: I had written that a switch fails to happen because sensitivity is "set high enough" — backwards. Higher sensitivity (level 7, "Ludicrous Speed") means a *smaller* PowerScore gap and *more* switching; a switch failing to fire points to *low* sensitivity, a long cooldown, or a long delay. Watch for this specific inversion any time prose talks about "raising" or "high" settings and switching frequency — sensitivity runs the opposite direction from cooldown and delay.
- Global English's "never let `this`/`which` point at a whole clause" catches real ambiguity, not just style noise: `troubleshooting.md`'s FAQ had "which shows a Select Leagues prompt" hanging off an entire prior clause, and a body paragraph opened "Within its league's section" with `its` referring to a noun (`a game`) that hadn't been introduced yet in the sentence. Both read fine on a fast pass and only surfaced under a deliberate pronoun-by-pronoun check.
- **Frontmatter gotcha, must recheck every time `faq` entries change:** an unquoted YAML plain scalar containing `: ` (colon-space) breaks `astro sync` outright — this is how Ryan caught `standby-stream.md`'s second faq answer between sessions. `python3 -c "import yaml; yaml.safe_load(...)"` against just the frontmatter block is a fast way to check before handing work back; running `cd apps/docs && npx astro sync` is the real proof and should be the last step of any session touching `faq:` blocks in this collection.
