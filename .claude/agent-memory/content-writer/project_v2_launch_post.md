`apps/docs/src/content/blog/introducing-v2.mdx` went through three passes on 2026-08-16. Pass 1 was rejected for paraphrasing the changelog, corny voice, and non-computing blog components (see [[feedback_deep_dive_structure]], [[feedback_blog_voice_corny]], [[feedback_blog_components_must_compute]]). Pass 2 fixed the tone and was explicitly approved ("The tone has much improved though") but Ryan said it left too much out — the ~2,300-word draft covered maybe 20 of ~76 changelog entries in the 2.0 range, and he specifically wanted the UI work covered in full: "SO much UI work was done in v2."

Pass 3 expanded the same file to ~6,900 words across 18 h2 sections (8 announcement, 10 deep-dive) without touching the four previously-approved deep-dive sections' existing sentences (only inserted new paragraphs into them). New deep-dive sections added: "A tutorial that kept rewriting itself" (the walkthrough's 4→5→8-step arc, verified against the *current* `walkthroughStepPowerScore.tsx` rather than trusting the changelog's blow-by-blow — the changelog's "Automated Looping Bloom" and "removed description boxes" entries turned out **not** to match the shipped code, which still shows a tap-to-advance bloom with full description text; the post describes the verified current behavior, not the changelog's account of it), "The breakdown stops being read-only" (tooltips, signal toggles + renormalization, boost/penalty icon table), "One card, rendered by three surfaces" (packages/ui extraction, color-pair normalization, SCSS/SVG cleanup — with two new interactive components, see below), "The docs site runs the same code it's showing you" (hero animation + animated explainer), "Twelve locales, and the bugs that ship with them" (i18n engineering: YAML→JSON, named-substitution bug, pt/pt_PT bug), "The tools that kept two months of rewrites honest" (Zod, Cypress, OXLint, TS7 unification). The announcement half grew a new "A walkthrough, if you want one" section and a "What you see when you open a game" section (pregame poster, live detail screen, flip clock, Game Info panel, down-and-distance field position, delay indicator), plus shorter additions to "Every sport, one tab" (league reorder, date-range setting) and "Twelve languages" (Ludicrous Speed one-liner, deliberately *not* claiming it's translated in all twelve — see the Filipino finding below).

**New components, both verified against [[feedback_blog_components_must_compute]]'s bar:** `apps/docs/src/components/blog/GameCardExplorer.tsx` imports the real `GameCard` dispatcher from `@arenaswap/ui/src/components/gameCard` (which picks `LiveGameCard` vs `PreGameCard` off `game.status`) and the real `computePowerScore` from `powerscore`, run against five reader-selectable game states (NBA live, NFL 4th-and-goal with real down/distance/odds fields, World Cup shootout, MLB rain delay whose PowerScore comes back 0 from the same real engine, NFL pregame with weather). `ColorPairExplorer.tsx` imports the real `resolveTeamColorPair` from `@arenaswap/ui/src/components/colorUtils` and lets the reader edit all four team color/alternate-color inputs directly. Both reuse the existing `.signal-breakdown` / `.signal-breakdown-controls` / `.signal-breakdown-preset-btn` CSS classes for visual consistency with `SignalBreakdown`/`PeriodExplorer`; new CSS added to `apps/docs/src/styles/global.scss` is scoped to `.game-card-explorer-stage` and `.color-pair-*`.

**Found but not fixed, flagged in the report:** `apps/docs/src/components/PowerScore.tsx` still has the stale mid-cycle signal ceilings (30/28/28/18/14 vs. the real 42/38/38/18/20) — carried over from pass 2, still out of scope. **New finding this pass:** `apps/extension/locales/fil.json` (Filipino) has ~20% of its keys byte-identical to `en.json` (vs. 2.6–5% for de/fr/ja/zh_CN/it/ko/zh_TW, which is the expected overlap for proprietary terms and placeholders), including the *entire* `ludicrousSpeed.*` block — all 11 keys, full multi-line Spaceballs dialogue, verbatim English. This means the existing, previously-approved "Twelve languages" paragraph's claim ("Every one is a full translation, not a subset... adapted rather than translated word for word") is not accurate for Filipino specifically. I did not edit that sentence (it predates this pass and rewriting approved copy on a mid-task discovery felt like a judgment call for Ryan, not something to do unilaterally), but I did *not* extend the new Ludicrous-Speed sentence or the new i18n deep-dive section to claim full-translation coverage for Filipino/Italian/Korean/Traditional Chinese (those four have no dedicated changelog entries either, per the existing verified-counts note below). This needs a decision: soften the "Twelve languages" claim, or hand `fil.json` to the i18n-polyglot-translator agent to actually finish it.

**Verified counts, re-derived from source rather than older copy:** 31 leagues per `packages/powerscore/src/constants.ts`. 12 locale files ship (de, en, es, fil, fr, it, ja, ko, pt_BR, pt_PT, zh_CN, zh_TW) but only 7 of them (en, es, de, fr, ja, zh_CN, pt/pt_BR) have dedicated changelog PRs in the 2.0 range — it/ko/fil/zh_TW landed with no entry of their own, confirmed again this pass by direct inspection of the locale files rather than the changelog.

**Repo-state note, still true:** `apps/docs/src/components/blog/` has no git history prior to this post (never committed before pass 2's rewrite).

Build verified this pass: `npx turbo run build typecheck lint --filter=@arenaswap/docs` → 5/5 tasks successful.
