Configura uma vez.
Vê tudo.

Abre os teus streams, associa-os a jogos e podes ir embora descansado. A partir daí, o ArenaSwap trata de cada mudança.

  1. Abre os teus streams.

    Abre os teus jogos em separadores de browser diferentes. Qualquer serviço de streaming que funcione num browser funciona com o ArenaSwap.

  2. Associa cada separador.

    Abre a extensão, encontra cada jogo na lista e liga-o ao separador certo com um único menu suspenso.

  3. O melhor jogo encontra-te.

    O ArenaSwap pontua cada jogo em directo e muda automaticamente para o mais emocionante. Tu só tens de ver.

Vê porquê. Sempre.
