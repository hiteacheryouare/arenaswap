  • Get started with ArenaSwap

    Install the ArenaSwap extension, choose your leagues, open two live streams, and watch it switch your tab to the better game automatically.

  • How to watch multiple games at once

    Open each stream in its own tab, assign it to a game in ArenaSwap, and let PowerScore decide which tab deserves your attention.

  • How to control when ArenaSwap switches tabs

    Adjust the auto-switch toggle, sensitivity, cooldown, and switch delay so ArenaSwap switches exactly as often as you want it to.

  • How to set favorite teams in ArenaSwap

    Star your teams to give their games a PowerScore bonus and pin them to the top of the list, without hiding anyone else's games.

  • How to set up Standby Stream

    Give ArenaSwap a fallback tab so it parks you somewhere good instead of leaving you on a blowout when every game you track goes quiet.

  • ArenaSwap settings reference

    Every setting in the ArenaSwap popup, grouped the way the popup itself groups them, with its default value and its full range.

  • Try ArenaSwap with Demo mode

    Turn on Demo mode to run 15 scripted games through the real PowerScore engine and watch a tab switch without waiting for a live game.

  • Troubleshoot ArenaSwap

    Fixes for the most common ArenaSwap problems, from an empty game list to switches that never happen, traced back to what the extension is actually doing.
