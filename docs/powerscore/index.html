PowerScore.PowerScore.
The score behind every NFL score.

PowerScore is the standalone package that turns any live game into a real-time excitement score from 0 to 100. The exact engine ArenaSwap uses to decide what game you should be watching next.

View on npm Source on GitHub

Install in one command

Pick your package manager, copy the command, and drop PowerScore into your app.

npm install powerscore

What goes into the number

Every signal contributes a weighted chunk of the final 100-point score. Higher score means higher drama right now.

Closeness · 30 max

How tight is the game right now? Tied games score highest.

Late-Game Pressure · 30 max

Final minutes and overtime ramp the score aggressively.

Momentum · 20 max

Unanswered runs and surges increase urgency.

Lead Changes · 12 max

Back-and-forth games beat one-sided games.

Comeback Factor · 8 max

If a trailing team is clawing back, the score rises.
