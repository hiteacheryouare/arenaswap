PowerScore.PowerScore.
The score behind every NFL score.

PowerScore turns any live game into an excitement score from 0 to 100, updated as the game moves. It is the same engine ArenaSwap uses to pick what you watch next, and it installs on its own.

View on npmSource on GitHub

Install in one command

Pick your package manager, copy the command, and PowerScore is in your app.

npm install powerscore

What goes into the number

Five signals stack into a score from 0 to 100. Their ceilings add up to more than 100 on purpose and the total is capped, so a close game climbs high and a blowout stays low. A higher score means more drama right now.

Closeness · 42 max

How tight is the game? Tied games score highest, and closeness counts for more the later it gets.

Late game · 38 max

Tension builds through the final period of a close game, and a tie heading to overtime scores higher still.

Momentum · 38 max

An unanswered run spikes the score, then fades over the next few minutes.

Lead changes · 18 max

A game that keeps trading the lead beats one that never does.

Comeback · 20 max

A trailing team clawing back raises the score.
