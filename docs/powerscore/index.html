PowerScore.PowerScore.
The score behind every NFL score.

PowerScore is the standalone package that turns any live game into a real-time excitement score from 0 to 100. The exact engine ArenaSwap uses to decide what game you should be watching next.

View on npmSource on GitHub

Install in one command

Pick your package manager, copy the command, and drop PowerScore into your app.

npm install powerscore

What goes into the number

Five signals stack into a 0–100 score. Their ceilings deliberately sum past 100 and the total is capped, so a genuinely exciting game climbs high while a blowout stays low. Higher score means higher drama right now.

Closeness · 30 max

How tight is the game? Tied games score highest, and closeness counts for more as the game goes on.

Late-Game Pressure · 28 max

Tension builds across the whole final period when the game is close, with a boost for tied games heading to overtime.

Momentum · 28 max

Unanswered runs spike the score, then fade over the next few minutes.

Lead Changes · 18 max

Back-and-forth games beat one-sided games.

Comeback Factor · 14 max

If a trailing team is clawing back, the score rises.
