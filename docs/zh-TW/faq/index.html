ArenaSwap 支援哪些聯盟？

涵蓋六種運動的 31 個聯盟。籃球：NBA、WNBA、NCAA Basketball、NCAA Women's Basketball，以及兩項奧運賽事。美式足球：NFL、NCAA Football 和 UFL。冰球：NHL、NCAA Men's Hockey，以及兩項奧運賽事。棒球和壘球：MLB、NCAA Baseball、NCAA Softball、世界棒球經典賽，以及奧運棒球。足球：英超、西甲、德甲、義甲、墨西哥甲級聯賽、美國大聯盟、美國女子足球聯賽、歐冠聯賽、歐霸聯賽，以及兩屆 FIFA 世界盃和兩項奧運賽事。

分頁切換是怎麼運作的？

你把每個已開啟的串流指派給一場比賽。ArenaSwap 會用 PowerScore 為每場直播比賽評分，當某場比賽的分數大幅超前你正在看的比賽時，它就會把你的分頁切換過去、取消該分頁的靜音，並把其他分頁靜音。靈敏度決定要領先多少才算「足夠」，冷卻時間則能避免你在兩場比賽之間來回跳動。

需要帳號或訂閱嗎？

不需要。ArenaSwap 完全免費，不需要帳號，也不會收集任何資料。它完全在你的瀏覽器裡執行，讀取 ESPN 公開的比分資料。你看的任何內容都不會被傳送到任何地方。

它能搭配我使用的串流服務嗎？

任何能在瀏覽器分頁中播放的串流都可以搭配使用，因為 ArenaSwap 是透過切換和靜音分頁來運作，而不是與特定服務整合。這涵蓋了 ESPN+、Peacock、Paramount+、YouTube TV、Hulu Live、Fubo，以及各聯盟的免費直播。但它沒辦法幫上原生 App 或機上盒的忙。

PowerScore 是怎麼運作的？

PowerScore 是一個 0 到 100 的評分，由五個訊號組成：比賽有多膠著、比賽進行到多後段、最近得分帶來的氣勢、領先方的變化，以及正在進行的逆轉規模有多大。每種運動對「膠著」的定義都不一樣，所以一分差距的冰球比賽和一分差距的籃球比賽會被同等看待。你支持的球隊和季後賽會加分；冷場的比賽會扣分，而處於延遲或中場休息的比賽則是零分。

我可以讓它不要從某場比賽切走嗎？

可以。取消該分頁的指派，ArenaSwap 就不會再理它，或者你也可以用彈出視窗上方的切換開關直接關掉自動切換。降低靈敏度或拉長冷卻時間，能讓切換變少，但不必整個關掉。

如果所有比賽都很無聊怎麼辦？

打開 Standby Stream 並選一個分頁。當你追蹤的比賽都沒有達到門檻時，ArenaSwap 會讓你停在那裡，而不是把你留在最不糟的那場比賽上。

原始碼有公開嗎？

有，公開在 GitHub 上，其中包含 PowerScore 演算法。這個演算法也單獨發布在 npm 上，所以就算不用擴充功能，你也能為比賽評分。
