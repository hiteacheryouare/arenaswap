如何同時觀看多場比賽

每場比賽開在各自的分頁，在 ArenaSwap 裡把分頁連到比賽，它就會帶你到最好看的那一場，並把其餘的靜音。

把比賽開在不同的分頁，告訴 ArenaSwap 哪個分頁是哪場，遙控器就交給它。

每場比賽開在自己的分頁

用你平常的方式開始每一場比賽，不管是哪個服務在轉播。只要每場比賽有自己的分頁，ArenaSwap 不在乎是哪一個。

把每個分頁連到它的比賽

在彈出視窗找到比賽的卡片，用它的 指派分頁 下拉選單挑它的分頁。尚未開賽的比賽也有同樣的下拉選單，所以你可以在開賽前先連好分頁。

已經連到別場比賽的分頁會變灰，並標示 （使用中）。想移過來，先從那場比賽取消連結。

讓 ArenaSwap 幫你配對

如果你已經開著的分頁看起來像比賽，列表上方會出現 這些分頁看起來像比賽 橫幅。點 查看，就能看到每場比賽和 ArenaSwap 認為與它對應的分頁。比對度高的會預設勾選。取消勾選它猜錯的，然後點 指派 3 個分頁（或你勾選的數量）。

關掉橫幅就會略過這些建議。

認識比賽列表

  • 活躍分頁 放你連好的比賽，最好看的在前，你收藏球隊的比賽排最上面。
  • 直播比賽 是其他所有正在進行的比賽，萬一有值得再開個分頁的。
  • 即將開賽 是接下來的比賽，一次一天。用箭頭換日期，用搜尋圖示找球隊、聯賽或頻道。
  • 已結束 顯示剛結束的比賽，但只有開啟 保留已結束的比賽 時才有。這些比賽不能連分頁。

比較喜歡每個聯賽一份列表？開啟 依聯賽分組比賽。

讓它跑

連好兩個以上的分頁後，由 ArenaSwap 決定你在哪一個。它會把每個連好的分頁靜音，只留下你正在看的那一個，等另一場明顯比螢幕上的更好看時，再帶你過去。你不用四處點，也不用按靜音。

想把某個分頁排除在輪替之外，從下拉選單取消連結。想完全停止切換，關閉頂端列的 啟用自動切換。

決定比賽結束後怎麼處理

設定裡的 比賽結束時 有三種選擇：

  • 保留分頁 是預設。
  • 從 ArenaSwap 釋放 會取消分頁的連結和靜音，並讓它保持開啟。
  • 關閉分頁 會把它關掉。

不管你選哪個，都要等到你離開那個分頁才會執行。視窗裡最後一個分頁會被釋放而不是關閉，所以視窗不會突然消失。下次打開 ArenaSwap 時，它會告訴你有幾個分頁回到你手上，像是「2 個分頁已還給你了。」

使用多個視窗

指派分頁 下拉選單列出的是你打開 ArenaSwap 的那個視窗裡的分頁。想連另一個視窗裡的分頁，就在那個視窗打開 ArenaSwap。當 ArenaSwap 切換到另一個視窗裡的比賽，那個視窗會移到最前面，全螢幕也會跟著過去。

怎麼在同一個瀏覽器同時看多場比賽？

每場比賽開在各自的分頁，然後在 ArenaSwap 的比賽卡片上選那個分頁。ArenaSwap 會帶你到最好看的比賽，並把其他的靜音。

ArenaSwap 能搭配任何串流服務嗎？

可以。只要比賽是在瀏覽器分頁裡播放，ArenaSwap 就能用。包括 Peacock、Prime Video、YouTube TV，還有你的有線電視業者的網站。

我最多能同時追蹤幾場比賽？

你開了多少分頁就能追蹤多少場。
