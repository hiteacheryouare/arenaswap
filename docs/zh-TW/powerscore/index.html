PowerScore.PowerScore.
每一個NFL比分背後的比分。

PowerScore 會把任何一場直播比賽轉換成 0 到 100 的精彩度分數，並隨著比賽進行即時更新。這跟 ArenaSwap 用來挑選你接下來要看哪場比賽的引擎完全一樣，而且可以獨立安裝。

在 npm 上查看GitHub 上的原始碼

一個指令就能安裝

npm install powerscore

這個數字是怎麼組成的

五個訊號加總成一個 0 到 100 的分數。它們各自的上限加起來刻意超過 100，而總分設有上限，所以膠著的比賽會衝得很高，一面倒的比賽則會維持在低分。分數越高，代表現在這一刻的看點越多。

膠著程度 · 最高 42

比賽有多膠著？平手的比賽分數最高，而且比賽越到後段，膠著程度的比重就越大。

比賽後段 · 最高 38

膠著比賽的最後一節，緊張感會不斷升高，走向延長賽的平手則分數更高。

氣勢 · 最高 38

一波沒有被回應的連續得分，會讓分數瞬間飆高，接著在接下來幾分鐘裡逐漸消退。

領先變化 · 最高 18

領先方不斷易主的比賽，勝過從來沒變過的比賽。

逆轉 · 最高 20

落後的一方奮起直追，會拉高分數。
