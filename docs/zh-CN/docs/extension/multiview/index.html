如何使用 Multiview

在一个浏览器标签页里并排观看最精彩的比赛，声音来自最好看的那一场。打开它，再选择何时启动。

Multiview 把您的精彩比赛放到同一个屏幕上，您不用再在它们之间做选择。最精彩的比赛占最大的一格，还有声音。

它只在 Chrome 和 Edge 里。Firefox 没有。

打开它

  1. 打开设置，选择 Multiview。
  2. 打开启用 Multiview。
  3. 一份简短的说明会告诉您会发生什么。依次点击下一步和继续。
  4. 浏览器会询问 ArenaSwap 能否“读取和更改您在所有网站上的数据”。请允许。这样您的流媒体才能一起显示在同一个标签页里。

如果点击暂不，或者在浏览器里选择不允许，Multiview 就保持关闭。其他功能都照常使用。

给每场比赛一个标签页

在各自的标签页里打开每场比赛的直播，然后在比赛卡片的分配标签页下拉菜单里选出对应的标签页。具体步骤见同时观看多场比赛。

请保持启用自动切换开着。关掉它，Multiview 就会关闭。

选择何时打开

Multiview 下的三项设置决定了这一点：

  • 精彩度达到是一场比赛要算作精彩所需的 PowerScore，范围是 0 到 100，默认是 55。往更常开启滑，Multiview 出现得更多；往仅限重大时刻滑，出现得更少。
  • 显示决定哪些比赛能得到一格。精彩比赛只显示达到或超过您所设分数的比赛，我的所有比赛显示每一场已分配标签页的比赛。
  • 最多分格数限制同时出现的比赛数量，范围是 2 到 8，默认是 4。如果符合条件的更多，PowerScore 最高的几场得到分格。

当您的比赛中至少有两场达到精彩度达到的分数时，Multiview 就会打开。它和其他任何切换一样，遵守您的切换冷却和切换延迟。这两项见控制 ArenaSwap 何时切换。

一旦有一场比赛精彩、另一场比赛的分数距离您的精彩度达到不到 10 分，一个静音的 Multiview 标签页就会在标签栏末尾打开，并开始加载这些比赛。如果第二场比赛的分数掉下去，这个标签页会保留 2 分钟，以防它回升。关掉这个标签页，Multiview 会先等完您的切换冷却，再重新尝试。

打开之后

ArenaSwap 会把 Multiview 标签页移到您的比赛旁边，或在那里新开一个，并带您过去。打开通知后，您会收到一条已切换 → Multiview 通知。

左上角最大的一格属于最精彩的比赛，也只有它有声音。其他比赛排在它周围。您的比赛标签页仍在后台开着，处于静音状态。

它何时关闭

Multiview 一旦打开，至少会停留一个切换冷却的时间，并且要等到其中一路直播开始播放。

当只剩一场比赛仍然精彩时，这场比赛会占满 Multiview 标签页 2 分钟。如果这段时间内另一场比赛又变得精彩，所有分格都会回来。否则，ArenaSwap 会带您到这场比赛自己的标签页，并关闭 Multiview。如果另一场比赛已经结束，或者您没有分格的某场比赛领先到足以切换过去，就会跳过这 2 分钟。

仅仅进入广告时段，比赛不会因此失去自己的分格。

您自己关掉 Multiview 标签页后，切换冷却一过，它还能再次打开。把它转到别的网页，它就会停下，并且 10 分钟内不会再重新打开这些比赛。

如果一分钟内没有任何一路直播开始播放，ArenaSwap 会带您回到最好看的比赛，并在 10 分钟后重试。如果某一格始终不播放，请把那路直播单独在一个标签页里打开，确认它在那里能正常播放。

怎样在浏览器的一个屏幕上看多场比赛？

在 ArenaSwap 设置里打开 Multiview，然后给您正在看的每场比赛分配一个标签页。当其中两场或更多同时变得精彩时，ArenaSwap 会打开一个标签页，每场比赛各占一格。

Multiview 能在 Firefox 上使用吗？

不能。Multiview 只在 Chrome 和 Edge 版的 ArenaSwap 里。Firefox 版有其他所有功能。

为什么 Multiview 没有打开？

请检查“启用自动切换”是否开着，是否已给至少两场直播比赛分配了标签页，以及其中至少两场是否达到了您设置的“精彩度达到”分数。ArenaSwap 还会先等完您的“切换冷却”和“切换延迟”。
