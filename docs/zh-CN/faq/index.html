常见问题。

如果这里没有您想了解的内容，请提交一个 issue

ArenaSwap 支持哪些联赛？

覆盖六项运动的 31 个联赛。篮球：NBA、WNBA、NCAA Basketball、NCAA Women's Basketball 以及两项奥运会比赛。橄榄球：NFL、NCAA Football 和 UFL。冰球：NHL、NCAA Men's Hockey 以及两项奥运会比赛。棒球和垒球：MLB、NCAA Baseball、NCAA Softball、世界棒球经典赛以及奥运棒球。足球：英超、西甲、德甲、意甲、墨西哥甲级联赛、美国大联盟、美国女足联赛、欧冠、欧联，以及两届 FIFA 世界杯和两项奥运会比赛。

标签页切换是如何运作的？

您将每个打开的直播流分配给一场比赛。ArenaSwap 会用 PowerScore 为每场直播比赛评分，当某场比赛的评分充分超过您正在观看的比赛时，它就会将您的标签页切换过去，取消该标签页的静音，并将其余标签页静音。灵敏度决定了领先多少才算“足够”，而冷却时间可以防止您在两场比赛之间来回跳转。

需要账户或订阅吗？

不需要。ArenaSwap 完全免费，无需账户，也不收集任何信息。它完全在您的浏览器中运行，读取 ESPN 公开的比分数据。您观看的任何内容都不会被发送到任何地方。

它能配合我使用的流媒体服务吗？

任何能在浏览器标签页中播放的直播流都可以配合使用，因为 ArenaSwap 是通过切换和静音标签页来工作的，而不是与某个服务进行集成。这涵盖了 ESPN+、Peacock、Paramount+、YouTube TV、Hulu Live、Fubo 以及各联赛的免费直播。但它无法帮助原生应用或机顶盒。

PowerScore 是如何运作的？

PowerScore 是一个 0 到 100 的评分，由五个信号构成：比赛的胶着程度、比赛的进程、近期得分带来的势头、领先方的变化，以及正在进行的逆转的规模。每项运动对“胶着”的定义各不相同，因此一分差距的冰球比赛和一分差距的篮球比赛会被同等对待。您支持的球队和季后赛会加分；冷场的比赛会被扣分，而处于中断或中场休息的比赛评分为零。

我可以阻止它从某场比赛切换走吗？

可以。取消该标签页的分配，ArenaSwap 就不会再管它；您也可以通过弹出窗口顶部的开关直接关闭自动切换。降低灵敏度或延长冷却时间可以让切换变得更少，而无需完全关闭它。

如果所有比赛都很无聊会怎样？

打开 Standby Stream 并选择一个标签页。当您追踪的比赛中没有一场达到阈值时，ArenaSwap 会让您停留在那里，而不是把您留在最不糟糕的那场比赛上。

源代码是否公开？

是的，公开在 GitHub 上，其中包括 PowerScore 算法。该算法也单独发布在 npm 上，因此您即使不使用扩展程序，也可以为比赛评分。
