ArenaSwap 2.2：节目表上线

节目表把一整天的赛程放进一个屏幕，比赛页面自带标签页，每场您打开的比赛还有一段开场。

还记得电视节目表吗？每个频道、每个钟点、一张大表格，某个地方还有位老爸拿红笔圈出周日的双场连赛。我们想念它，于是自己做了一个，然后停不下来：带数据统计和联赛排名的比赛页面，给已结束的比赛一个像样的告别，还有一段开场，把每场对阵都当成值得一套转播包装来对待（它确实值得）。

以下是今晚的节目预告。

节目表

弹窗很擅长回答“我现在该看什么？”，却答不好“八点我该看什么？”。即将开赛只给您一串开赛时间，看不出形状，所以您看不出四点钟有六场比赛撞在一起，也看不出您的两支球队是背靠背开打。

点弹窗顶栏里新的节目表按钮，会打开一个完整的浏览器标签页，把当天的比赛画成时间轴：

  • 每场比赛是一条横杠，从真实的开赛时间开始，长度是该联赛比赛通常的时长，按联赛归组
  • 直播中的横杠带着比分和比赛时钟；已结束的显示终场比分，输的一方变暗；即将开赛的显示开赛时间和转播频道
  • 已结束比赛的横杠，在比赛真正结束的地方结束；还在加时的直播比赛，会越过它原本的时段继续变长，而不是假装能准时打完
  • 最佳观赛时间区带标出同时开打的比赛最多的那一段，偏重重要的比赛和您的收藏球队。在今天的页面上，它只往前看
  • 一天一天地翻页，翻到您的即将开赛设置能到的地方为止（至少三天）。它在今天打开，而且只有今天这一页有当前时间线
  • 点任意一场比赛，真正的比赛页面会在表格旁边滑出来，PowerScore 和图表一应俱全。您的球队得分时还有彩带。我们可不是野蛮人

比赛页面有标签页了

点进一场比赛，现在它分成概览、数据统计和排名，不再是一条长长的滚动页。

  • **数据统计：**分节比分、两队对比，以及一次一支球队的球员数据，每项运动只保留最要紧的六列。
  • **排名：**整个联赛，分区按分会归组，画面上这两支球队用各自的颜色突出。大学篮球和大学橄榄球改为显示这场对阵所在的联盟，因为完整的表有几百支球队，您根本不会滚到那里
  • 标签页即时切换。没有渐隐，中间也不会闪出一个看不清的比分

直播比赛页面还多了几样东西，是我们在现场的线人一直悄悄递过来的：

  • 有排名的球队，名字前面会带上排名数字
  • 橄榄球队用圆点显示剩余的暂停次数
  • 上一次进攻有了自己的区块，放在页面顶部，边缘用做出这次进攻的球队的颜色
  • 棒球在球数下面显示谁在投球、谁在击球，而且每半局换边，这样每位球员始终站在自己球队的下方

终场哨响之后

已结束的比赛以前一结束就消失，很不礼貌。在设置 > 显示里打开保留已结束的比赛，它们会在即将开赛下方新的已结束分区里再待 24 小时。点一场进去，是一张总结页：终场比分（带上规范的 Final/OT 或 Final/SO）、比赛打了多久、来了多少观众，还有整场比赛的全套图表。

那您给这些比赛分配的标签页呢？看完整整一个周六，您会剩下十几个标签页，开着赛后面板和各种暴论。在比赛结束时下选择怎么处理：

  1. 不动这个标签页
  2. 从 ArenaSwap 释放它（取消静音，变回您自己的标签页）
  3. 关掉它

您正在看的标签页，在您离开前不会被动；如果一场已结束比赛的标签页是它所在窗口里的最后一个，我们会释放它而不是关闭。在我们手里，没人的窗口会凭空消失。

开场

打开 ArenaSwap，每场比赛现在都以一张对阵海报登场：两个队徽大到卡片装不下，两种球队颜色擦入，在一条斜线接缝处相遇，两队全名亮出来，然后一条白条横扫而过，揭开下面的卡片。每天第一次打开是长版，之后每次是快版。前八场比赛会有这个效果，因为一个有三十场比赛的周六，不需要同时有三百个东西在动。

想直接跳到比分？在设置 > 显示里关掉开场动画。下次打开弹窗时生效。

我们顺手还改了一处：滚动时弹窗顶栏现在会钉在顶部，ArenaSwap 字标会折叠成图标。网站的顶栏也是同样的把戏。

队徽、颜色和更多细节

  • 队徽始终是球队真正的队徽，用球队真正的颜色。只有当主色和对手的颜色冲突时，球队才会换成它的第二种颜色
  • 队徽不会再在定型之前闪一下全彩原图
  • 巨人队的“ny”不再被顶栏里的圆圈裁掉
  • 橄榄球的两个达阵区，都写着守护它的球队的昵称和队徽，50 码线上现在也有一个队徽
  • 比赛页面上的队徽变大了
  • 颜色冲突的 NHL 球队（Sabres 和 Blue Jackets 的海军蓝，Hurricanes 和 Panthers 的红色）保留各自的颜色，不会再有一支被塞进我们的橙色
  • 五支以前在图表上显示成灰色的海军蓝球队，又变回海军蓝了
  • 篮球比分图表不再从零开始，所以一场胶着的比赛不会再像两条平线
  • 顶栏会倒数还没开始的比赛，而不是显示 0–0
  • 中场休息、终场这样的字，不再用电子记分牌字体来打扮

季后赛，按曲线评分

季后赛加成以前不管是外卡赛还是总决赛，都是固定的 +5。现在它随着奖杯越来越近而增长：首轮是加成的四分之一，到决赛是全额（默认加成提到了 8）。卡片上也会显示这是哪一轮。整理全部 31 个联赛的时候，我们修了几处搞混的地方：世界杯的三十二强赛被当成常规赛来评分，NCAA 棒球和垒球的轮次顺序是反的，全明星赛 Pro Bowl 则被当成分区决赛来加分。它是表演赛。大家都知道它是表演赛。

向线人报到少一点，丢的比赛也少一点

  • 一个联赛如果接下来一天都没有比赛，它的哨兵就放一晚上假，不再每隔几分钟报到一次
  • 繁忙的周六，直播的大学橄榄球比赛不会再丢了
  • 我们的线人安静一会儿时，我们不会再把它当成“今天没有比赛”
  • 已结束的比赛，不会再因为联赛出了点小状况，或是时钟走过美东午夜，就消失
  • 弹窗一打开，不会再同时去问所有联赛；节目表用我们已经知道的比赛，不再重新到处问一遍

彩蛋、转圈圈，以及其他要紧事

  • Ludicrous Speed 彩蛋照着真正的电影重做了一遍，连格子隧道都有。它在舰桥和飞船后方视角之间切换，点一下就能跳过。隐藏的速度控制没有了。什么控制？对，就是这样
  • 加载转圈圈学会了 39 个新笑话，多了不少冰球、足球、网球和板球，还有几处我们法律上不能点名的著名体坛闹剧
  • 另外，有一条加载提示好几个月来一直说要把“coolors”装满，没人吭声。现在改成 coolers 了 🧊
  • 球队选择器加载时，用的是和弹窗其他地方一样的橙色转圈圈
  • 鼠标悬停时，设置齿轮会转起来。绝对必要。没人要求过

其他节目：

  • **弹窗更轻了。**每次打开要加载的东西少了很多，图表要等您真的打开一场比赛才加载
  • **穹顶球场不再报告外面的天气。**有顶棚的比赛上，不会再出现雷暴标签（或十二月的雪）
  • 您设置的切换冷却，不会再在浏览器歇口气时悄悄重置
  • 被取消的进球，不再被算成对方的势头转折
  • 胜率图表不再偶尔出现空白
  • Standby Stream 的横条，不再是白底深色字的一大块
  • 评价提示不再出现在加载转圈圈下面
  • 开场动画播放时，弹窗不再左右晃动（原来它一直有点晃）
  • 扩展和网站现在都改用同一套动画时长，如果您让电脑减少动态效果，它们也都会照做
  • 网站上的实时演示，在您滚过它或切换标签页之后，会停止查看比赛
  • 网站的安装按钮，会把 Firefox 和 Edge 的访客带去各自的商店
  • 一大堆幕后整理工作，我们就不多说了，包括一小队新测试，上面一半的修复就是靠它们找到的
