ArenaSwap 2 来了

更强大，更多运动，更多乐趣

八月下旬。冠军争夺越来越紧，NFL 季前赛让所有板凳球员都觉得自己今年能首发，而某个地方有一场足球赛，毫无理由地打进了点球大战。

2.0 版来了，我们这段时间可没闲着。我们把 PowerScore 拆开重造，从一项运动扩展到六项，加进 31 个联赛，给弹窗装上真正的归档系统，教会比赛卡片说棒球和足球的话，围绕真实的产品重建了网站，总之就是确保：只要有值得看的比赛，ArenaSwap 就知道。

坐稳了。这一篇很长。

更多联赛，更多乐趣！

ArenaSwap 现在覆盖篮球、橄榄球、冰球、棒球、垒球和足球六项运动的 31 个联赛。也就是 NBA、WNBA、NCAA 篮球锦标赛、NFL、NCAA 橄榄球、UFL、NHL、NCAA 男子冰球、MLB、NCAA 棒球、NCAA 垒球、世界棒球经典赛、十三项足球赛事，以及七项奥运赛事。简单说：只要涉及球、冰球、对阵表，或者数量可疑的加时赛，我们多半有兴趣。

我们也让选联赛这件事不那么烦人了：

  • 关掉一个联赛，我们就彻底不再查它。只选 NBA 的设置，不会再背着您悄悄轮询其他三十个记分牌
  • 重新打开一个联赛，它会记得您原来把它放在哪，而不是像一个走散的孩子那样自己掉到最底下
  • 把联赛拖成您觉得合理的任何顺序。比赛列表、即将开赛和各分区标题都会跟着变
  • 只有当您真的偏离了默认顺序，才会出现恢复按钮。这点权力，我们信任您

PowerScore 从头重建

PowerScore 决定哪场比赛配得上您的标签页，所以我们觉得它大概应该擅长这件事。旧系统能告诉您一场比赛精彩。新系统的意见要强烈得多。

  • 每个信号都有了更大的发挥空间。接近度、关键时刻、势头、领先权易手和逆转，现在在总分封顶 100 之前，能贡献的分数多得多
  • 我们加了一项新的调整：波动性，它盯着实时的胜率线。一场在 50/50 附近徘徊的比赛最多能得五分；一场一个小时前就已成定局的比赛可以扣五分。恰如其分，它是唯一能让 PowerScore 倒退的调整
  • 比赛现在是在变得精彩的过程中逐步累积分数，不再一开场就给一个笼统的“嗯，有点动静”的分数
  • 一边倒的比赛已经被正式告知：最后一分钟不会让它们变成胶着的比赛。领先 30 分，还是领先 30 分
  • 战平的比赛有了自己通向加时赛的小坡道，因为加时赛在即的平局，正是我们希望您注意到的那种局面
  • 中场休息、休息、雨天中断和其他停滞状态，现在一律强制归零。没有哪场停下来的比赛，还能继续兑现它停下来之前挣到的精彩
  • 得分机会现在懂得看场合了。45–3 的比赛里一次红区机会，和一分之差比赛里的第四档 goal-to-go 不是一个价。棒球和垒球反过来处理：垒上有跑垒员，视那个小小的内野有多拥挤，最多能贡献十分
  • 每项运动现在都有自己对“胶着”的定义。冰球里差一球，和篮球里差一分，不是同一种局面；第九局差三分，和橄榄球里差三分，也该得到截然不同的反应
  • 势头也按各项运动合适的速度衰减：篮球 45 秒，足球四分钟，以此类推。篮球里的一波攻势不该永远缠着记分牌；足球里罕见的一粒进球，该多留一会儿

没错，世界杯决赛终于算季后赛了。我们旧的季后赛检测器很懂美国联赛，显然认为世界上其他地方的体育只是闹着玩。世界杯、欧冠、奥运会和世界棒球经典赛，一直缺着季后赛加成。现在我们能处理线人给淘汰轮编码的全部三种方式，包括那些有个迷人习惯、把金牌赛归档成“常规赛”的奥运项目。

有好戏时查得快，然后小睡一会儿

我们给每个联赛配了自己的轮询计时器，计时器会留意最好的那场比赛有多好。

  • 有一场真正惊险比赛的联赛，最快每六秒查一次
  • 安静的联赛放缓到 25 秒
  • 休息时间拉长到 40 秒
  • 连续两次轮询都是空的，联赛就进入两到三分钟的睡眠周期
  • 31 个计时器全部错开，还加了随机抖动，因为让三十一个联赛在同一时刻拍我们线人的肩膀，似乎不太礼貌

所以 ArenaSwap 把注意力花在比赛真正进行的地方。

Standby Stream：因为有时候一切都很无聊

有些夜晚，您盯着的每场比赛同时变成 41–3 的一边倒、雨天中断或休息。以前，ArenaSwap 的回答基本上是：*嗯，祝您好运。*现在您可以选一个 Standby Stream。当所有比赛都跌破您设的阈值，ArenaSwap 会把您停在您选的备用标签页上。一旦有什么变精彩了，您马上被送回去。

  • 您自己从待机标签页离开，ArenaSwap 就会领会这个暗示
  • 排队中的切换，如果比赛在等待期间变得无趣，就会被取消
  • 第一次启用时，会有一份两页的小说明，告诉您刚刚放出来的是什么
  • 待机标签页和其他受管理的标签页一样静音，不会突然变成您电脑上最吵的东西

您的备用方案，现在有了备用方案。

设置不再是 20 项的滚动噩梦

我们的设置页面以前是一长串竖排的滑块、开关和神秘的小数字，Standby Stream 藏在离顶部大约三个地质年代之外的地方。我们给它加了目录。

现在有六个类别：切换、评分、联赛、显示、Standby Stream 和演示模式。每个类别都能不用滚动，装进 320×560 的弹窗。联赛享有这条规则的豁免，因为 31 个联赛，还是 31 个联赛。

还有搜索。输入“playoff”就能找到季后赛加成；输入“spam”就能找到切换冷却。搜索用的是各语言自己的关键词列表，所以我们不会让您读着德语的设置，却要用英文名去搜它。

还有几处清楚多了：

  • 灵敏度滑块现在会准确告诉您每一档的含义：分差 37、27、18、11、6、3 或 1 分，ArenaSwap 才会换标签页
  • 说明挪进了提示气泡，不再永久占着弹窗里宝贵的地盘
  • 投注盘口默认关闭，在您开口要之前一直关着
  • 开启后，盘口旁边会显示博彩公司自己的标志

比赛页面终于有新鲜话说了

旧的比赛页面基本上就是把您刚点的卡片放大。球队名，又来。比分，又来。时钟，又来。现在详情页真的带着凭据来了。

  • 四张图表：PowerScore 随时间的变化、比分走势、胜率，以及堆叠的信号分解
  • 季后赛系列赛追踪，显示像“BOS 以 3–2 领先系列赛”这样的信息，每场比赛一个圆点
  • 球队战绩，从第一天起就在我们的数据里，显然一直在耐心等待大展身手的机会
  • 距离跳球、开球、开冰、第一球的实时倒计时
  • 一个完全独立的赛前页面，而不是假装还没开始的比赛得了 0/100
  • 一张赛前海报，给每个队徽配一个带色调的圆盘，因为深海军蓝的标志放在深海军蓝的背景上，技术上看得见，精神上看不见
  • 比赛开始前您能决定的两件事，目标标签页和手动 PowerScore 加成，现在放在一起
  • 场地、转播和赔率有了真正的行，天气并入场地信息，显示设置里还有 °F/°C 切换
  • 滚过大图之后，一条紧凑的对阵条会跟着您，带着两个队徽、比分和比赛状态

手动加成也是唯一允许把 PowerScore 推过 100 的东西。因为有时候，您就是得相信一场比赛。

卡片学会了所报道运动的规则

我们受够了让每项运动都假装自己是篮球。

棒球现在有真正的垒包菱形、有人的垒位、好球/坏球/出局数，以及上半局/下半局指示。足球现在有加1和加2、点球大战的“点球”、能越过 90 分钟继续走的时钟，以及点球比分，不会再永远冻在 120 分钟。橄榄球现在会告诉您球到底在哪：“2nd & 11”配上了场上位置指示，因为只知道第几档，不知道球在哪，只算知道了一半。

停下来的比赛终于会告诉您为什么停了：中场休息写中场休息，休息写休息，雨天中断写Rain delay，还会换上黄色边框。不用再盯着一个冻住的时钟，猜大家是去了更衣室，还是老天爷赢了。

赛前用语也按运动区分：跳球、开球、开冰、第一球，以及它们各语言的对应说法。德语是“Bully”。日语是プレイボール。而且，我们显然已经走进了未来：比分数字变化时会翻动。持续 350 毫秒。没人要求过，人人都会注意到。

队徽的位置再也不会是空的

每个队徽都是从我们的线人实时取来的，也就是说，从“请给我标志”到“标志在这”之间，有一小段空档。以前，这段空档看起来是个窟窿。在一个有 31 个联赛的引导页上，那可能是一大堆窟窿。

现在每个队徽从第一帧起，就有一个灰调的占位圆盘，上面是球队首字母。真标志到了，很好。没到，这个位置看起来也是故意的。

  • 请求标志失败按网址分别记录，所以新的请求会再得到一次机会
  • 有三处特意不用首字母处理，因为那样只会和旁边的文字重复
  • NBA、NHL、NFL 和 NWSL 不再神秘地变成“N”，因为取每个单词的第一个字母，并不是什么高明的缩写识别器

Se habla deportes!

ArenaSwap 现在除英语外，还有德语、法语、意大利语、西班牙语、日语、韩语、简体中文、繁体中文、菲律宾语、欧洲葡萄牙语和巴西葡萄牙语。每个非英语语言文件都包含全部 546 个键。没有缺失的翻译。没有半屏中间突然冒出一句英文的意外。基本上：菲律宾语还缺 Spaceballs 那一块。我们宁愿自己承认，也不想让您悄悄发现。

其他重要的本地化进展：

  • “Ludicrous Speed”在日语里成了「バカ速モード」，在中文里成了“荒唐速度”
  • 加载界面里的食物按地区变化：费城奶酪牛肉三明治在葡萄牙变成 bifana，在德国变成咖喱香肠
  • “go birds”到处都还是“go birds”，因为有些东西不必翻译
  • 73 条加载提示、7 个空状态和 28 条情境小贴士，都已翻译
  • 信号名称在每个页面都统一了，因为一页写“Closeness”，另一页写“Igualdad”，对谁都没好处

您可以再看一遍导览。我们查过了。

首次启动现在是三步：标签页切换怎么运作，您想看哪些联赛（NBA、NFL、NHL 和 MLB 已预选），以及您关注哪些球队，实时从我们的线人加载。线人安静一会儿时，有跳过和重试的路径。

完整的导览一共八步，以彩带收尾。仅 PowerScore 那一节，就有十二个可互动的小步骤，因为要解释五个评分信号，显然得有它自己的小游乐园。

导览也不会在安装之后消失。想再看一遍，随时点顶栏里的 ?。还有演示模式，12 个联赛里的 15 场预设比赛，加上模拟的季后赛系列赛，这样您可以真正看着 ArenaSwap 做出决定，不用等下一场六小时的棒球赛变精彩。

您的设置跟着您走

偏好设置现在会分别写入同步存储和本地存储。以最新的值为准，如果一种存储机制有配额问题，另一种不会被拖进烂摊子。在另一台电脑上登录同一个浏览器个人资料，您的联赛、收藏、阈值和其他偏好都会跟过来。

我们也给了 ArenaSwap 更多自我说明的方式：

  • 切换通知现在会告诉您比分、场地和切换的原因
  • Standby Stream 有了自己的通知
  • 通知可以在显示设置里单独开关
  • 您球队得分时，会用球队的颜色撒彩带
  • 提示条会确认设置已保存这类安静的事

因为有时候，最让人安心的消息，就是：对，您刚改的那个东西，真的保存了。

网站不再假扮扩展

旧网站里有一个手工搭的弹窗复制品：108 行 CSS，人眼比对，手动更新。您大概能猜到后面发生什么了。

网站现在导入真正发布的组件。同样的卡片，同样的外壳，同样的图表，同样的产品。主页再也不会描述一个三个月前就不存在的界面。

PowerScore 页面也在您的浏览器里，用真实的算法跑真实的比赛。它不再画一张假图来解释 PowerScore。它就是 PowerScore。PowerScore 现在还是一个可安装的 npm 包，安装命令就摆在那儿。

网站的其余部分也得到了同样的待遇：

  • 主视觉视频现在用的是三场真实的比赛：北亚利桑那对夏威夷、陆军对海军、明尼苏达州立对贝米吉州立
  • 球队队徽和卡片来自我们的线人，而不是页面连名字都没提的球队的素材视频
  • 一段自动播放的讲解，用真实的走势线，分四个场景带您走过 PowerScore 引擎
  • 发布说明有了专属页面和 RSS 订阅
  • 现在有了 FAQ 和一个精心设计的 404
  • 隐私、许可、致谢和条款，都有了真正的网址

因为显然，“链接在页面上某个地方”，对 Chrome 应用商店的审核员来说还不够好。

我们把整个网站大声读了一遍。有些句子没能活下来。

我们对每个页面做了一遍文案检查。结果发现，除了别的以外，我们的 PowerScore 页面一直自信满满地宣传着五个错的数字。其中四个是纯粹的错。它们现在直接取自真正的评分常量，几乎没有机会再长出各自的主意。

我们还修了一段被一个捣乱的撇号从句子中间截断的 meta 描述，去掉了破折号，让被动句重新有了主语，把每处“英雄区”都换成“顶部的视频”（因为“hero”是给做网站的人用的词，不是给要读网站的人用的），并从文档页里删掉了“planned”，因为在发布之前就宣布一个版本，是不小心制造预言的好办法。

关错标签页不会再让 ArenaSwap 失灵

我们审查了标签页切换的路径，发现了件有趣的事：ArenaSwap 其实从来没发现过受管理的标签页被关掉。所以如果放着最佳比赛的标签页消失了，ArenaSwap 可能就此安静地过完整个晚上。没有报错，没有恢复。全凭感觉。

这个现在修好了。

  • 关掉的标签页会立刻被忘掉，而不是在登记表里作祟直到重启
  • 如果榜首的比赛消失了，切换会给第二名
  • 排队的切换在真正触发时会重新评估，所以不会把您送去一场在切换等待期间已经结束的比赛
  • 手动导航到一场比赛后，ArenaSwap 会按您的冷却时间退让，而不是立刻试图把控制权抢回去
  • 关掉切换再打开，冷却会正确重置
  • 静音标签页的状态能熬过 service worker 休眠，所以 ArenaSwap 不再管理它们之后，标签页不会被留在静音里
  • 后台测试从 13 个增加到 27 个，包括对真正的切换决策路径的直接覆盖

现在，快问快答 ⚡

当然还有更多：

  • Tailwind CSS 其实没有在扩展里编译。我们找到了大约 18KB 的死源码，和一份 21,463 字节、显然一直在独自干所有活的样式表
  • 中断和暂停的比赛现在得分强制为零，而不是靠中断之前的精彩一路滑行
  • 即将开赛按日期分组，收藏优先，上限十场，提供“显示更多”，还能选一到十四天的范围
  • 收藏的比赛固定在所在联赛分区的顶部，您可以直接从比赛卡片或赛前海报收藏一支球队
  • 主列表把已有标签页的比赛和没有的分开
  • 天气状况现在把 44 个标签对应到真正的图标，不再像一个陷入困境的天气 API 那样，冲着您打印“Partly Cloudy/Windy”
  • 即使您改了设置就立刻关掉弹窗，设置也照样保存
  • 一套代码现在服务 Chrome、Firefox 和 Edge，只要三项权限，没有内容脚本，Firefox 把 ArenaSwap 列为完全不收集数据
