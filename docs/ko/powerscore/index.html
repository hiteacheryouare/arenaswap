빅 모먼트엔 보너스 점수.

미식축구

  • 투 미닛 드릴+12

    하프 막판에 동점이거나 한 스코어 차 이내로 뒤진 채 공격을 이어갈 때.

  • 레드존+15

    접전 경기에서 20야드 안쪽까지 들어간 드라이브. 4th 다운이 가장 크게 쳐줘요.

야구와 소프트볼

  • 노히터+70

    6회부터(소프트볼은 4회부터) 안타가 없는 팀이 있을 때.

  • 역전 주자 출루+10

    역전 또는 동점 주자가 출루해 있을 때. 후반 이닝에서 더 크게 쳐줘요.

  • 주자 출루+10

    주자가 나갈 때마다 점수가 더해지고, 만루일 때 가장 커요.

아이스하키

  • 파워플레이 또는 골리 빼기+20

    두 골 차 이내의 경기이거나, 마지막 4분 동안 골리를 뺐을 때.

축구

  • 퇴장+15

    동점이거나 한 골 차인 경기에서 퇴장이 나온 뒤 10분 동안.

모든 종목

  • 이변 주시+12

    경기 전 열세였던 팀이 경기 중반을 넘어 앞서거나 비기거나 한 스코어 차 이내로 뒤질 때.

  • 중요도+10

    벼랑 끝에 선 시리즈, 랭킹 팀끼리의 맞대결, 시즌 막판 순위 경쟁.

감점

  • 광고 시간−15

    경기가 광고 시간일 때 최대 15점이 깎여요.

  • 승리 확률±5

    승부가 50대 50에 가까우면 최대 5점이 더해지고, 한 팀이 사실상 굳히면 최대 5점이 깎여요.

라이브 PowerScore.

내 프로젝트에서 써 보세요.

PowerScore는 npm에서 무료예요. 스코어, 시계, 그리고 내 피드가 아는 나머지 정보를 넣으면 0에서 100 사이의 숫자와 그 이유를 돌려줘요.

설치하기.

$ npm install powerscore

경기 채점하기.

import { scoreGame } from 'powerscore';

const score = scoreGame({
	id: 'game-1',
	league: 'nba',
	sportType: 'basketball',
	status: 'in',
	homeTeam: { nickname: 'Celtics', score: 104 },
	awayTeam: { nickname: 'Knicks', score: 103 },
	period: 4,
	clockSeconds: 134,
});

score.total;  // 63
score.reason; // "Celtics up 1 with 2:14 left"

스코어와 시계부터 시작하세요.

접전도와 막바지는 이것만으로 충분해요. 아래 필드를 추가할 때마다 더 많은 요소가 켜지고, 없는 필드는 빼도 돼요.

넣는 것그러면 켜지는 것
스코어, 시계, 피리어드접전도와 막바지
스코어 스냅샷 몇 개, 오래된 순서대로모멘텀, 리드 변경, 추격
폴링할 때마다의 승리 확률±5 승리 확률 변동
다운, 거리, 필드 위치, 공격권투 미닛 드릴과 레드존
주자, 아웃, 안타주자 출루, 역전 주자, 노히터
파워플레이와 빈 골대하키의 득점 찬스
퇴장퇴장 부스트
경기 전 배당이변 주시
내 판타지 로스터판타지 모드

내 피드를 가져오세요.

처음 보는 리그에는 해당 종목의 기본값이 적용돼요. 내 리그의 피리어드 구성이 다르면 호출에 함께 넘겨 주세요.

import { scoreGame, type Game } from 'powerscore';

const fromRink = (row: BeerLeagueRow): Game<string> => ({
	id: row.rink,
	league: 'tuesday-d-league',
	sportType: 'hockey',
	status: 'in',
	homeTeam: { score: row.home },
	awayTeam: { score: row.away },
	period: row.frame,
	clockSeconds: row.minutesLeft * 60,
});

const score = scoreGame(fromRink(row), {}, {
	league: { regularPeriods: 3, periodDurationSecs: 15 * 60 },
});
