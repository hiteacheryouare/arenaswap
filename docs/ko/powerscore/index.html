PowerScore.PowerScore.
매 NFL 점수 뒤에 숨은 점수.

PowerScore는 모든 라이브 경기를 0에서 100까지의 흥미도 점수로 바꾸고, 경기가 진행되는 동안 계속 업데이트해요. ArenaSwap이 다음에 볼 경기를 고를 때 쓰는 것과 같은 엔진이며, 단독으로도 설치할 수 있어요.

npm에서 보기GitHub 소스 코드

명령어 하나로 설치

npm install powerscore

숫자를 구성하는 요소

다섯 가지 시그널이 쌓여 0에서 100까지의 점수가 돼요. 각 시그널의 상한을 더하면 의도적으로 100를 넘지만, 합계에는 상한이 있어서 접전인 경기는 높이 올라가고 일방적인 경기는 낮게 유지돼요. 점수가 높을수록 지금 이 순간의 드라마가 크다는 뜻이에요.

접전도 · 최대 42

경기가 얼마나 팽팽한가요? 동점 경기가 가장 높은 점수를 받고, 경기 후반으로 갈수록 접전도의 비중이 커져요.

막바지 · 최대 38

접전인 경기의 마지막 피리어드에서 긴장감이 높아지고, 연장전으로 향하는 동점은 더 높은 점수를 받아요.

모멘텀 · 최대 38

응답 없는 연속 득점이 점수를 확 끌어올린 다음, 이후 몇 분에 걸쳐 서서히 가라앉아요.

리드 변경 · 최대 18

리드가 계속 바뀌는 경기가 한 번도 안 바뀌는 경기를 이겨요.

역전 · 최대 20

뒤처지던 팀이 따라잡으면 점수가 올라가요.
