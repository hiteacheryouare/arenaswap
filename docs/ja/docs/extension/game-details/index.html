ArenaSwap の試合詳細画面の見方

試合をクリックすると、その順位の理由、ここまでの展開、出場選手、視聴先が分かります。ゲームブーストで1試合を押し上げることもできます。

試合をクリックすると、その順位の理由と、何がかかっているのかが分かります。

試合を開く

ポップアップの試合カードをクリックします。番組表では、試合のバーをクリックするとサイドパネルで開きます。リストに戻るには戻るを、番組表では閉じるをクリックします。

スコアの下にタブが並びます。概要は常に表示され、対戦は試合開始前、ボックススコアは試合が始まってから、順位表はそのリーグに順位表があるときに表示されます。全部は収まらない場合、残りはその他にまとまります。

試合の順位が高い理由を見る

ライブ中の試合を開き、概要のPowerScore内訳を見ます。その試合が観る価値のある理由が分かります。

  • 接戦度: 点差がどれだけ詰まっているか。
  • 終盤: 勝負がまだ分からないまま、試合の終わりがどれだけ近いか。
  • 勢い: 一方のチームが連続得点で乗っているか。
  • リード交代: 最近、リードが何回入れ替わったか。
  • 追い上げ: 負けているチームが追い上げているか。

それぞれのポイントの後に、ブースト（お気に入りチームなどによる加点）とペナルティ（コマーシャル中などによる減点）が続き、最後に最終PowerScoreが出ます。合計の下の一文は、いま何が効いているかを伝えます。

ハーフタイム、インターバル、中断で止まっている試合は、プレーが再開するまで0と表示されます。終了した試合には PowerScore が付きません。何を評価するかの変え方はスコアリングモードにあります。

試合の流れを追う

内訳の下のグラフは、試合が進むにつれて埋まっていきます。PowerScoreの推移は試合がいつ面白くなったかを、勝利確率は形勢がどう揺れたかを示します。スコアとリードのグラフもあります。

ライブ中の試合では、競技に応じてさらに表示が増えます。最新プレーは直前の出来事を示し、野球では次の打順が次に打席に立つ選手を示します。フットボールではダウンと距離、バスケットボールではタイムアウトとボーナスが出ます。プレーオフの試合にはシリーズの成績が表示されます。

試合開始前に準備する

まだ始まっていない試合には、まもなくキックオフのカードが出ます（競技によってティップオフ、パックドロップ、初球の場合もあります）。ここでゲームブーストを追加でき、ポップアップでは試合を開くタブも選べます。

その下には、該当する競技なら先発投手や先発ゴーリー、主要選手、そして直近の成績、シーズン成績、負傷者が載った対戦タブがあります。チームをお気に入りにするには、エンブレムの横のスターをタップします。その効果はお気に入りチームで説明しています。

ボックススコアと順位表を見る

ボックススコアには、観ている競技に合わせて、ピリオドごとのスコア、チームの成績、選手ごとの記録が載っています。順位表には、リーグの順位表が表示され、この2チームが強調されます。

視聴先を探す

試合情報には、放送局や配信サービス、会場、天気が載っています。終了した試合には観客数も表示されます。これからの試合にはチケットへのリンクが付くことがあります。

ベッティングのラインは、設定でベッティング & オッズを表示をオンにしたときだけ表示されます。

ゲームブーストを追加する

スコアがどうあれ、この試合を画面に出したい。そんなときはゲームブーストで PowerScore にポイントを足すと、ArenaSwap が選ぶ回数が増えます。0〜100の数字を入力し、解除するには0にします。

ゲームブーストの欄は、ライブ中の試合とこれからの試合にあります。PowerScore を100より上にできる唯一の設定で、内訳では「ゲームブースト」と表示されます。

試合の PowerScore がその数字になった理由はどこで分かりますか？

ポップアップの試合カード、または番組表の試合バーをクリックします。ライブ中の試合なら、概要タブの PowerScore内訳に加点の中身が表示され、いちばん下に分かりやすい一文が付きます。情報アイコンにカーソルを重ねると、それぞれの項目の意味が分かります。

ArenaSwap のゲームブーストは何をしますか？

1試合の PowerScore に0〜100ポイントを足して、ArenaSwap がその試合を選びやすくします。0に戻せば解除されます。

試合詳細画面にベッティングのラインが表示されないのはなぜですか？

設定で「ベッティング & オッズを表示」をオンにしていないと表示されません。

この試合に対戦、ボックススコア、順位表のタブがないのはなぜですか？

タブは、中に入れる内容があるときだけ表示されます。対戦は始まる前の試合、ボックススコアは始まってからの試合向けです。順位表がないリーグもあります。
