# Security Policy

## Supported Versions

ArenaSwap supports the **latest published version** and any prior versions that remain in active
use according to Chrome Web Store analytics. Once a version has been fully replaced via automatic
browser updates, it is no longer eligible for security fixes.

| Status | Criteria |
| --- | --- |
| ✅ Supported | Latest published version |
| ✅ Supported | Prior versions still in active use (Chrome analytics) |
| ❌ Not supported | Versions with no remaining active users |

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public issue.**

Use GitHub's private advisory feature to report it confidentially:

1. Go to the [Security tab](../../security/advisories/new) of this repository
2. Click **"Report a vulnerability"**
3. Fill out the form with as much detail as possible

We'll acknowledge your report as soon as we can and keep you updated as we work toward a fix.
We appreciate responsible disclosure and will credit reporters in the release notes (unless you
prefer to remain anonymous).
