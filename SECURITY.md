# Security Policy

## Overview

The ArenaSwap project takes security seriously. This policy describes our supported versions, how to report vulnerabilities responsibly, and our commitment to addressing security concerns.

## Supported Versions

Security updates are provided for the following versions:

| Version | Status |
| --- | --- |
| Latest published | ✅ Actively supported |
| Prior versions in active use* | ✅ Actively supported |
| Versions with no active users | ❌ Not supported |

*Active use is determined by Chrome Web Store analytics. Once a version has been fully replaced through automatic browser updates, it is no longer eligible for security fixes.

## Reporting a Vulnerability

We ask that security researchers and users report vulnerabilities responsibly and discreetly, using our private reporting mechanism rather than public issue channels.

### How to Report

1. Navigate to the [Security Advisories](../../security/advisories/new) tab of this repository
2. Click **"Report a vulnerability"**
3. Complete the form with:
   - A clear description of the vulnerability
   - Steps to reproduce (if applicable)
   - Potential impact assessment
   - Any suggested remediation

### What to Expect

- **Acknowledgment**: We will confirm receipt of your report promptly
- **Updates**: We will keep you informed of progress toward a fix
- **Timeline**: We aim to address confirmed vulnerabilities with urgency appropriate to their severity
- **Credit**: Researchers will be credited in release notes (you may request anonymity)

## Responsible Disclosure

We appreciate your commitment to coordinated disclosure. Please:

- **Do not** open public issues for vulnerabilities
- **Do not** disclose the vulnerability publicly before we have issued a fix
- **Allow reasonable time** for us to develop and release a patch before public disclosure
- **Provide clear technical details** to help us verify and address the issue

## Security Best Practices for Users

When using ArenaSwap:

- Keep your browser and extensions updated to the latest version
- Review permissions granted to the extension
- Report any suspicious behavior or unexpected access to your browser data

## Questions?

If you have questions about this security policy, please reach out through the private advisory form rather than opening a public issue.
