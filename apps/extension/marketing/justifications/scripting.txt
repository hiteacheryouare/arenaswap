ArenaSwap uses chrome.scripting.registerContentScripts() for Multiview, the optional view that shows several live games side by side on one page in the Chrome and Edge builds. When the user opens Multiview, the extension registers one content script (multiviewFrame) for all frames. It returns at once unless the page at the top of the frame tree is the extension's own Multiview page. A frame that hides its ancestors leaves the page's media untouched, asks the Multiview page once, and stops if there is no answer. Inside a Multiview box, the script mutes and unmutes the stream by volume, starts playback in the box being brought on air, and reports whether a video is playing, so the extension knows when a box is ready and which game is on air. The registration does not persist across browser sessions, and chrome.scripting.unregisterContentScripts() removes it when the Multiview tab closes. Until the user turns Multiview on in settings and grants its optional site access, the permission is inert: no script is registered and no page is touched. The Firefox build does not request it.
