ArenaSwap uses chrome.webNavigation.getFrame() inside its Multiview page, the optional view that shows several live games side by side in the Chrome and Edge builds. A streaming site often nests its video player several frames deep, and the player reports its playback status from there. The extension calls getFrame() on the Multiview tab to walk from the reporting frame up through its parent frames to the box it sits in, so the status is credited to the right game. Nothing else uses the permission, and it reads only frame relationships in the Multiview tab: no page content, history or navigation events. It is an optional permission, requested with chrome.permissions.request() only when the user turns Multiview on, and removed with chrome.permissions.remove() when they turn it off. The Firefox build does not request it.
