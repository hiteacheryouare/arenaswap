ArenaSwap requests optional access to all sites (<all_urls>) only when the user turns Multiview on, and never at install. Multiview is an optional view that shows several live games side by side in the Chrome and Edge builds. Each box loads a streaming page the user registered, and the video player inside it usually lives on a different domain than that page, so the extension cannot name the sites in advance. The request is made with chrome.permissions.request() from the Multiview toggle in the popup, in direct response to the user's click, together with the optional webNavigation permission. The access lets the extension's frame script run inside those boxes and lets its session rule apply to them. It is used only inside the Multiview tab. Turning Multiview off calls chrome.permissions.remove(), and the user can revoke it at any time from the browser's extension settings. If the user declines the prompt, Multiview stays off and nothing else in ArenaSwap changes. The Firefox build does not request it.
