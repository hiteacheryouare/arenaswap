ArenaSwap uses chrome.storage.local to persist the user's settings between browser sessions: sensitivity level, switch cooldown, switch delay, favorite-team bonuses, enabled leagues, and the current tab-to-game assignments. The same settings are written to chrome.storage.sync so they follow the user to other browsers they are signed into; whichever copy was written most recently wins on load. chrome.storage.session holds short-lived state that must not outlive the browser session, such as which tabs the extension has muted, so a tab cannot be left silent if the service worker is torn down. Without storage, the user would lose every preference and re-assign every tab on each browser restart. No personally identifiable information is stored, and synced data contains nothing beyond the settings listed above — it is handled by the browser's own sync and never sent to an ArenaSwap server.
