ArenaSwap uses chrome.storage.local to persist the user's settings between browser sessions: sensitivity level, switch cooldown, switch delay, favorite-team bonuses, enabled leagues, saved profiles, the Fantasy roster, team colours, recently ended games, which introductions the user has seen, and short-lived caches of team logos and college conference lists. The active profile's settings and Fantasy roster are also written to chrome.storage.sync so they follow the user to other browsers they are signed into; whichever copy was written most recently wins on load. chrome.storage.session holds state that must not outlive the browser session: which tab is assigned to which game, the Standby Stream tab, which tabs the extension has muted, and Multiview state, so a tab cannot be left silent if the service worker is torn down. Without storage, the user would lose every preference on each browser restart. No personally identifiable information is stored, and synced data contains nothing beyond the settings, roster and profile name listed above. It is handled by the browser's own sync and never sent to an ArenaSwap server.
