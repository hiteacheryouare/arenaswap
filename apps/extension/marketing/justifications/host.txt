ArenaSwap fetches live scoreboard data from ESPN's public scoreboard API at site.api.espn.com to calculate PowerScore for every live game across the supported leagues. Each league has its own scoreboard endpoint under this host (e.g., /apis/site/v2/sports/basketball/nba/scoreboard), so wildcard access to the host is required to poll all enabled leagues. No authentication is used; only public scoreboard endpoints are accessed.
---
ArenaSwap displays each game's team logos in the popup UI to help users identify games at a glance. Team logos are served from ESPN's CDN at a.espncdn.com under per-team paths (e.g., /i/teamlogos/nba/500/13.png), so wildcard host access is required to load logos for any team across any supported league. No other content is fetched from this host.
---
ArenaSwap also reads three kinds of public data from ESPN's core API at sports.core.api.espn.com: the live situation of a game (for example down and distance, or runners on base), player details for the Fantasy roster, and the college conference lists used by the college division and conference filters. These are unauthenticated GET requests to /v2/sports/{sport}/leagues/{league} endpoints, and no other content is fetched from this host. This host is not listed in host_permissions: ESPN's servers answer cross-origin requests from the extension without it.
