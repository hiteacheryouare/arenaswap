ArenaSwap requests declarativeNetRequestWithHostAccess for Multiview, the optional view that shows several live games side by side on one page in the Chrome and Edge builds. Streaming sites usually send X-Frame-Options and Content-Security-Policy headers that stop them being shown inside another page. When Multiview opens, the extension calls chrome.declarativeNetRequest.updateSessionRules() to add one session rule that removes those two response headers, scoped by tabIds to the Multiview tab alone and by resourceTypes to sub_frame requests, so no other tab or top-level page loses them. The rule is removed when the Multiview tab closes. Until the user turns Multiview on in settings and grants its optional site access, the permission is inert: no rule exists and no response is modified. The WithHostAccess variant means the rule can act only on sites the user has granted. The Firefox build does not request it.
