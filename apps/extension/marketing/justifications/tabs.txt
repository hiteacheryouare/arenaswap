ArenaSwap's core function is switching the user's active tab to whichever assigned game is currently most exciting. This requires the tabs permission to call chrome.tabs.update() to activate the target tab, chrome.tabs.query() to list tabs the user can assign games to in the popup, and chrome.tabs.update({ muted }) to unmute the active game's tab while muting all other assigned tabs so the correct broadcast audio plays. The user explicitly assigns each tab to a game via a dropdown in the popup before any switching occurs.
