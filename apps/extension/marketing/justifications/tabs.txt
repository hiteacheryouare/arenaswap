ArenaSwap's core function is switching the user's active tab to whichever assigned game is currently most exciting. This requires the tabs permission to call chrome.tabs.update() to activate the target tab, chrome.tabs.query() to list tabs the user can assign games to in the popup, and chrome.tabs.update({ muted }) to unmute the active game's tab while muting all other assigned tabs so the correct broadcast audio plays. The user explicitly assigns each tab to a game via a dropdown in the popup before any switching occurs. chrome.tabs.create() opens only these: ArenaSwap's own Multiview, settings backup and welcome pages, the extension's store review page, and, when the user presses the boss button, a blank tab or the web address the user entered as their decoy page. chrome.tabs.remove() closes the Multiview tab when it ends, the backup page once its job is done and, only when the user has chosen to close finished games' tabs, the tab of a game that has ended.
