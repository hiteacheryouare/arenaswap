May dumaan, at hindi tamang tingnan ang tab na puno ng overtime. Itinatago ng boss button ang mga laro sa isang galaw.

## Ano ang ginagawa nito

Kapag pinindot mo, ang ArenaSwap ay:

- Ime-mute ang mga game tab mo.
- Ipo-pause ang awtomatikong paglipat, kaya walang hihila sa iyo pabalik sa laro nang kusa.
- Dadalhin ka sa decoy page mo.

## Paano ito pindutin

- I-click ang incognito icon sa top bar ng popup.
- O pindutin ang **Alt+Shift+X** mula sa kahit anong tab. Hindi mo na kailangang buksan muna ang popup.

## Piliin ang pekeng pahina mo

Buksan ang Mga Setting, piliin ang **Paglipat**, at hanapin ang **Pekeng pahina**. Maglagay ng kahit anong web address na mukhang abala, gaya ng spreadsheet o doc. Pindutin ang Enter o mag-click sa labas ng box para ma-save.

- Kung bukas na ang pahina, lalaktaw ang boss button sa tab na iyon.
- Kung hindi pa, bubuksan ito ng ArenaSwap para sa iyo.
- Iwanang walang laman ang box at blangkong tab ang makukuha mo.
- Web address lang ang tinatanggap. Kapag iba, lalabas ang "Mukhang hindi iyan web address."

## Ibalik ang mga laro

Hindi bumabalik sa dati ang boss button nang mag-isa. Kapag ligtas na, buksan ang popup at i-on ulit ang **I-enable ang awtomatikong paglipat**. Nandoon pa rin ang mga tab at assignment mo sa mga laro.

## Palitan ang shortcut

Magtakda ng bagong key para sa **Parating na ang boss** sa extension shortcuts page ng browser mo:

- Chrome: `chrome://extensions/shortcuts`
- Edge: `edge://extensions/shortcuts`
- Firefox: Add-ons Manager, ang gear menu, tapos **Manage Extension Shortcuts**

Kung ginagamit na ng ibang extension ang Alt+Shift+X, pumili ng ibang key doon. Kahit walang shortcut, gumagana pa rin ang button kapag kinlick.
