I-setup nang isang beses ang ArenaSwap, magbukas ng dalawang laro, at ililipat ka nito sa mas magandang laro. Ilang minuto lang ito.

## I-install at piliin ang mga liga mo

I-add ang ArenaSwap mula sa Chrome Web Store, Firefox Add-ons, o Edge Add-ons store, tapos i-click ang toolbar icon nito. Gagabayan ka ng maikling setup sa natitira.

Welcome ang unang screen. I-click ang **Gets Ko!**. Kung nagamit mo na ang ArenaSwap sa ibang computer, dadalhin ng **May backup file ka? Laktawan ang setup at i-import ito** ang mga setting mo. Nasa [Mga profile at backup](/arenaswap/docs/extension/profiles-and-backup/) ang tungkol sa file.

Sa **Anong mga sports ang pinapanood mo?**, i-check ang mga ligang sinusubaybayan mo. Naka-check na agad ang NBA, NFL, NHL, at MLB. May **Lahat** na box ang bawat sport kung gusto mo ang buong grupo. I-click ang **Susunod**. Puwede mong baguhin ang listahang ito sa Mga Setting anumang oras.

## I-star ang mga team mo

Sa **Piliin ang mga Team Mo**, i-tap ang team para i-star ito. May dagdag na bump ang mga naka-star na team kapag pumipili ng laro ang ArenaSwap, kaya mas madalas manalo ng paglipat ang mga laro nila. Nasa [Mga paboritong team](/arenaswap/docs/extension/favorite-teams/) ang mga detalye.

I-click ang **Tapos na**, o **Laktawan** kung ayaw mo pang pumili.

Mapupunta ka sa **Handa ka na!** I-click ang **Simulan ang Tour** para sa mabilis na walkthrough, o **Diretso na**. Ang **?** button sa itaas ang magpapaulit ng tour mamaya.

## Magbukas ng dalawang live na laro

Simulan ang dalawang laro sa dalawang magkahiwalay na browser tab, sa kahit anong pinapanoodan mo na. Walang dalawang live na laro ngayon? I-on ang [Demo mode](/arenaswap/docs/extension/demo-mode/) at gamitin ang mga scripted nito.

## Ikabit ang bawat tab sa laro nito

Buksan ang popup ng ArenaSwap. Sa card ng bawat laro, gamitin ang **Mag-assign ng tab** na dropdown para piliin ang tab na binuksan mo para sa larong iyon.

Bukas na ba ang mga stream? Baka may banner na **Mukhang mga laro ang mga tab na ito** na mag-aalok na i-match ang mga ito para sa iyo. I-click ang **Tingnan** para suriin ang mga hula nito.

<Demo name='popup' tabs />

Aakyat sa **Mga Aktibong Tab** sa itaas ng listahan ang mga nakakabit na laro. Sa mga tab lang na ikinabit mo lumilipat ang ArenaSwap.

## Panoorin ang paglipat

Iwanang bukas ang dalawang tab at manood ng laro. Kapag mas naging exciting ang isa pa, dadalhin ka ng ArenaSwap doon, ia-unmute ito, at imu-mute ang iniwan mo. Kapag naka-on ang **Mga Abiso sa Paglipat**, na siyang default, makakatanggap ka rin ng maikling abiso kung ano ang nangyari at bakit.

## Ano ang susunod

- Ang [Paano manood ng maraming laro nang sabay](/arenaswap/docs/extension/watching-multiple-games/) ay tungkol sa pagkakabit ng maraming tab at pagkaka-ayos ng listahan ng laro.
- Ang [Paano gamitin ang Multiview](/arenaswap/docs/extension/multiview/) ay naglalagay ng ilang laro sa isang screen, sa Chrome at Edge.
- Ang [Paano kontrolin kung kailan lumilipat ang ArenaSwap ng tab](/arenaswap/docs/extension/switching-and-sensitivity/) ay tungkol sa bilis at tiyaga nito.
- Ang [Gabay sa mga setting ng ArenaSwap](/arenaswap/docs/extension/settings/) ay naglilista ng bawat setting.
