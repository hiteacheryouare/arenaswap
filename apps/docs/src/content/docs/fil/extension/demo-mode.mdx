Binibigyan ka ng Demo mode ng mga practice game, para makita mong lumipat ang ArenaSwap ng tab kahit walang totoong laro. Swak ito sa off-season, o kapag gusto mo muna itong subukan bago pagkatiwalaan ang browser mo.

## I-on ito

1. Buksan ang Mga Setting at piliin ang **Paglipat**.
2. Sa ilalim ng **Demo**, i-on ang **Demo Mode**.

Mapupuno ang listahan ng mga practice game mula sa iba't ibang liga. Lalabas ang mga ito naka-on man o hindi ang mga liga nila, at patuloy na gumagalaw ang mga score. May bumubuo ng lamang. May nagko-comeback.

<Demo name='toggle' setting='setup.demoMode' />

## Subukan ang paglipat

Mag-assign ng tab sa dalawa o tatlong demo game, gaya ng gagawin mo sa totoong laro. Nasa [Manood ng maraming laro](/arenaswap/docs/extension/watching-multiple-games/) ang mga hakbang.

Magandang pagkakataon din ito para subukan ang mga slider sa [Paano kontrolin kung kailan lumilipat ang ArenaSwap ng tab](/arenaswap/docs/extension/switching-and-sensitivity/). Makikita mo agad kung ano ang ginagawa nila.

Lalabas ang **Magpanggap na** kapag naka-on ang Demo mode. Ang pinapalitan lang nito ay ang mga holiday decoration.

## I-off ito

I-off ulit ang **Demo Mode**. Mawawala ang mga practice game at babalik ang mga totoong laro mo.

## Kaugnay

- Ang [Simulan ang ArenaSwap](/arenaswap/docs/extension/getting-started/) ang unang puntahan kung hindi ka pa nakakapag-setup.
- Ang [Paano kontrolin kung kailan lumilipat ang ArenaSwap ng tab](/arenaswap/docs/extension/switching-and-sensitivity/) ay tungkol sa mga setting na sulit subukan dito.
