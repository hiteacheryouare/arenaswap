点开任何一场比赛，就能看到它为什么排在这个位置，以及它背后押着什么。

## 打开一场比赛

点击弹窗里的比赛卡片。在[节目表](/arenaswap/docs/extension/guide/)里，点击比赛的条形块，它会在侧边面板中打开。点击**返回**回到列表，在节目表里则点击**关闭**。

比分下方有一排标签页：**概览**始终都在，比赛开始前会出现**对阵**，比赛进行后出现**数据统计**，如果您的联赛有积分表，还会出现**排名**。放不下的会收进**更多**。

## 看看一场比赛为什么排得这么高

打开一场直播中的比赛，查看**概览**里的 **PowerScore 详细分析**。它会显示是什么让这场比赛值得一看：

- **接近度**：比分咬得有多紧。
- **关键时刻**：比赛离结束有多近，而胜负仍未分晓。
- **势头**：是否有一方正在打出攻势。
- **领先权易手**：最近领先权换了几次手。
- **逆转**：落后的一方是否正在追上来。

每一项都会显示各自的分数，接着是各种加成（额外加分，比如为您收藏的球队加分）和扣分（比如广告时段扣分），最后是**最终 PowerScore**。总分下面那一句话，说的是此刻是什么在推动它。

处于**中场休息**、**休息**或中断的比赛显示为 0，直到比赛重新开始。已结束的比赛没有 PowerScore。想改变哪些因素算数，见[评分模式](/arenaswap/docs/extension/scoring-modes/)。

## 跟上比赛的进展

详细分析下方的图表会随着比赛进行不断补全。**PowerScore 走势**显示这场比赛是什么时候变好看的，**胜率**显示赔率是怎么摆动的。另外还有比分和分差的图表。

<Demo name='charts' />

直播中的比赛还会按运动项目增加更多内容。**最新战况**显示刚刚发生了什么，棒球里**后续击球员**显示接下来谁上场击球。橄榄球会显示进攻次数与码数，篮球会显示暂停和罚球加罚状态。季后赛会显示系列赛比分。

## 开赛前先做好准备

还没开始的比赛会有一张**即将开球**卡片（视运动项目而定，是跳球、冰球开球或首球投出）。在这里可以添加比赛加成，在弹窗里还能选择用哪个标签页打开这场比赛。

卡片下方，如果适用，还有**先发投手**或**先发守门员**、**主力球员**，以及**对阵**标签页里的**近期战绩**、**赛季数据**和**伤病**。想关注一支球队，点一下队徽旁的星标。想知道这有什么用，见[收藏球队](/arenaswap/docs/extension/favorite-teams/)。

## 查看数据统计与排名

**数据统计**按节次列出比分，并给出您所看运动项目的球队数据和球员数据。**排名**显示联赛积分表，并突出这两支球队。

## 找到观看渠道

**比赛信息**列出频道或服务、场馆和天气。已结束的比赛还会显示上座人数。未开始的比赛可以链接到**门票**。

只有在设置里打开了**显示投注与赔率**，才会显示投注盘口。

## 添加比赛加成

不管比分怎么样，都想让某场比赛上屏？**比赛加成**会给它的 PowerScore 加分，让 ArenaSwap 更常选中它。输入 0 到 100 之间的数字，输入 0 即可取消。

<Demo name='game-boost' />

比赛加成输入框出现在直播中和未开始的比赛上。它是唯一能把 PowerScore 推过 100 的东西，详细分析里会把它显示为“比赛加成”。
