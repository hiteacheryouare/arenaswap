ArenaSwap 只需设置一次。打开两场比赛，它就会把您带到更好看的那一场。只要几分钟。

## 安装并选择联赛

从 Chrome 网上应用店、Firefox 附加组件或 Edge 加载项商店添加 ArenaSwap，然后点击工具栏上的图标。一个简短的设置流程会带您完成剩下的步骤。

第一个画面是欢迎页，点击**明白了**。如果您在另一台电脑上用过 ArenaSwap，点击**有备份文件？跳过设置，直接导入**，就能把设置带过来。备份文件的详情见[个人资料与备份](/arenaswap/docs/extension/profiles-and-backup/)。

在**您喜欢看哪些运动？**里，勾选您关注的联赛。NBA、NFL、NHL 和 MLB 默认已勾选。每项运动都有一个**全部**勾选框，想要整组联赛就用它。点击**下一步**。这份列表可以随时在设置里更改。

## 给球队加星

在**选择您的球队**里，点一支球队就能给它加星。ArenaSwap 挑选比赛时，加星的球队会得到加分，所以它们的比赛更容易赢得切换。详情见[收藏球队](/arenaswap/docs/extension/favorite-teams/)。

点击**完成**；如果现在不想选，点击**跳过**。

接下来会进入**一切就绪！**。点击**开始引导教程**可以快速走一遍，也可以点击**直接开始**。以后想重看教程，点顶部的 **?** 按钮。

## 打开两场直播比赛

在两个不同的浏览器标签页里开两场比赛，用您平时看球的任何流媒体都行。现在没有两场直播比赛？打开[演示模式](/arenaswap/docs/extension/demo-mode/)，用它预设的比赛。

## 把每个标签页和它的比赛关联起来

打开 ArenaSwap 的弹窗。在每场比赛的卡片上，用**分配标签页**下拉菜单选出您为这场比赛打开的标签页。

流媒体已经开着了？可能会出现一个**这些标签页看起来像比赛**横幅，主动帮您配对。点击**查看**，核对它的判断。

<Demo name='popup' tabs />

关联好的比赛会移到列表顶部的**活跃标签页**里。ArenaSwap 只会在您关联过的标签页之间切换。

## 看它切换

让两个标签页都开着，安心看比赛。另一场变得更精彩时，ArenaSwap 会带您过去，为它取消静音，并把您离开的那场静音。打开**切换通知**（默认就是开着的），您还会收到一条简短提示，说明发生了什么、为什么切换。
