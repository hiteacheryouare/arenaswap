开箱即用时，ArenaSwap 会去找那种胶着、临近结束、局势来回摆动的比赛。这就是**经典**。如果您想在屏幕上看到别的类型，可以在设置的**评分**下改变它的寻找方向。

## 选择您想看的比赛类型

- **经典：**胶着的比赛、末段的戏剧性和大逆转。最后几分钟打成平手，就是理想局面。
- **一边倒：**比分悬殊的比赛，适合想看一支球队碾压另一支的时候。没有大比分碾压的夜晚，胶着的比赛仍会出现，但真正的碾压局总是优先。添加[宿敌](/arenaswap/docs/extension/favorite-teams/#pick-your-rivals)，它们的惨败局就会排在最前面。
- **梦幻：**有您球员上场的比赛。它会关注他们在比赛中的位置（谁拿着球、谁在击球、谁进入了红区），以及他们最近拿了多少梦幻得分。
- **自定义：**为每个联赛各设一种模式。比如 NFL 用梦幻，大学篮球用经典，其他都用一边倒。没有设置的联赛使用经典。

所有联赛的比赛都按同一个 0 到 100 的标尺排名，所以梦幻比赛和经典比赛依然可以争夺您的标签页。一场比赛要比当前的好多少，ArenaSwap 才会带您过去，仍然由您的[切换设置](/arenaswap/docs/extension/switching-and-sensitivity/)决定。

## 不错过您的球员

1. 把评分模式设为**梦幻**，或者设为**自定义**，并在您想要的联赛上选梦幻。
2. 打开**您的球员**，按姓名搜索球员，从结果里添加。最多可以添加 50 人。
3. 设置**您的球员能为比赛加多少分**。往上滑，您的阵容占比更重；往下滑，它只用来在难分高下时分出先后。

梦幻覆盖 NFL、NBA、WNBA、MLB 和 NHL。橄榄球阵容里还可以放一支球队防守组。有您球员上场的比赛只会在列表里上移，不会下移。

在**得分规则**下，您可以修改每项数据值多少梦幻得分。ArenaSwap 默认使用各项运动的标准得分。

## 关掉您不在意的

每种模式都会衡量几样东西，称为信号。经典的信号是接近度、关键时刻、势头、领先权易手和逆转。在 **PowerScore 信号**下，您可以关掉其中任何一个，只要留下一个。每个信号的含义，见[信号页面](/arenaswap/docs/powerscore/signals/)。

## 您自己添加的加分

这些在每种模式下都有效：

- **收藏球队加成**会给有您关注球队的比赛加分。见[收藏球队](/arenaswap/docs/extension/favorite-teams/)。
- **季后赛加成**会给季后赛和淘汰赛加分，越往后的轮次加得越多。它在一边倒模式下不适用。
- **比赛加成**会给您挑选的某一场比赛加分，范围是 0 到 100。可以在比赛详情页或[节目表](/arenaswap/docs/extension/guide/)里使用比赛加成输入框。它会一直保留到您关闭浏览器。
