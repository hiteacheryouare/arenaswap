ArenaSwap 預設會去找比分接近、時間接近尾聲、局勢來回擺盪的比賽。這就是 **經典**。想在螢幕上看到別的類型，到設定的 **評分** 底下改變它看重什麼。

## 選擇你想看的比賽類型

- **經典：** 比分接近的比賽、後段的戲劇性，還有逆轉。最後幾分鐘打成平手，就是夢想的畫面。
- **一面倒：** 比分懸殊的比賽，想看一隊把另一隊整個碾過去的時候用。沒有大比分輾壓的夜晚，接近的比賽還是會出現，但真正的輾壓一定會勝出。加入[宿敵](/arenaswap/docs/extension/favorite-teams/#pick-your-rivals)，它們的慘敗局就會排在最前面。
- **夢幻：** 有你的球員上場的比賽。它會追蹤球員在比賽中的位置（誰持球、誰在打擊區、誰進了紅區），以及他們最近拿了多少夢幻得分。
- **自訂：** 每個聯賽用不同的模式。也許 NFL 用夢幻，大學籃球用經典，其他全用一面倒。你沒設定的聯賽就用經典。

所有聯賽的比賽都用同一個 0 到 100 的尺度排名，所以夢幻比賽和經典比賽照樣能搶你的分頁。一場比賽要好多少，ArenaSwap 才會帶你過去，仍然由你的[切換設定](/arenaswap/docs/extension/switching-and-sensitivity/)決定。

## 不錯過你的球員

1. 把計分模式設為 **夢幻**，或選 **自訂**，並在你想要的聯賽使用夢幻。
2. 打開 **你的球員**，用名字搜尋球員，從結果中加入。最多可以加 50 位。
3. 調整 **你的球員能為比賽加多少分**。往上拉，你的陣容比重更大。往下拉，它只用來在勢均力敵時分高下。

夢幻涵蓋 NFL、NBA、WNBA、MLB 和 NHL。美式足球的陣容還可以放一支球隊的防守組。有你球員上場的比賽，只會在列表中往上移，不會往下掉。

在 **得分規則** 底下，你可以調整每項數據值多少夢幻得分。ArenaSwap 一開始用的是各項運動的標準得分。

## 關掉你不在意的項目

每種模式都有幾個衡量的項目，叫做信號。經典的信號是接近度、關鍵時刻、氣勢、領先交替和逆轉。在 **PowerScore 信號** 底下，你可以關掉任何一個，只要保留至少一個開著。每個信號的意思，請見[信號頁面](/arenaswap/docs/powerscore/signals/)。

## 你自己加的分數

這些在每種模式都有效：

- **收藏球隊加成** 會替有你追蹤球隊的比賽加分。請見[收藏球隊](/arenaswap/docs/extension/favorite-teams/)。
- **季後賽加成** 會替季後賽和淘汰賽加分，越後面的輪次加越多。一面倒模式不適用。
- **比賽加成** 會替你挑的某一場比賽加 0 到 100 分。用比賽詳細畫面或[節目表](/arenaswap/docs/extension/guide/)裡的比賽加成欄位設定。它會持續到你關閉瀏覽器為止。
