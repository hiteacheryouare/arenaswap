彈出視窗顯示現在有什麼比賽。節目表顯示一整天剩下的比賽，讓你知道什麼時候該清出沙發。

## 打開節目表

點彈出視窗頂端列上標著 **節目表** 的日曆圖示。它會在自己的瀏覽器分頁開啟，所以可以讓它跟你的比賽並排放著。

## 看懂時間軸

每一列是一場比賽，依聯賽分組，上方是時間刻度。

- 長條從比賽開始，延伸到大約預計結束的時間。
- 一條線標出現在的時間，今天的頁面開啟時會直接捲到那裡。
- 尚未開賽的比賽顯示開賽時間和頻道。進行中的比賽顯示比分和比賽時鐘。已結束的比賽顯示比分和 **終場**。
- 長條上有實心星號，代表你的其中一支球隊在比賽。
- 把游標移到長條上，會看到對戰組合和開賽時間。

你只會看到在設定裡開啟的聯賽。

## 看其他天

用 **前一天** 和 **後一天** 一次移動一天。沒有比賽的日子會被跳過。

能往後看多遠，由設定裡比賽列表底下的 **提前天數** 決定，可設 1 到 14 天，預設是 7 天。節目表至少會顯示 3 天。過去一天內結束的比賽會留在表格上。

## 找出最佳觀賽時間

**最佳觀賽時間** 預設是開啟的。它會把一天裡同時進行最多場比賽的時段標上底色。接近尾聲的比賽比剛開打的更有分量，你收藏的球隊也一樣。

頂端會寫明細節，像是「3 場比賽．其中 1 場是你的」。把開關關掉就會隱藏底色。

## 打開一場比賽

點任何一個長條，比賽會在右側的面板開啟。裡面有什麼，請見[比賽詳情](/arenaswap/docs/extension/game-details/)。

- 點另一個長條就換一場比賽，按 **關閉** 或 Escape 把面板收起來。
- 比賽開始前，可以替任一支球隊加星號。這支球隊在每個長條上都會顯示星號。
- 替你不想錯過的比賽加上 **比賽加成**。在開賽前加，ArenaSwap 一開始就會讓它領先一步。

想把比賽連到分頁，請用彈出視窗。節目表做不到。
