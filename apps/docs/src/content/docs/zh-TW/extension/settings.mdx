點彈出視窗頂端列的齒輪就能打開設定。用最上方的搜尋框，依名稱或你想做的事找設定。設定分成切換、評分、收藏球隊、聯賽、顯示、Standby Stream、Multiview，以及個人資料與備份。Firefox 沒有 Multiview。

## 切換

- **切換靈敏度**（**均衡**）：另一場比賽要比現在這場精彩多少，ArenaSwap 才會帶你過去。共七段，從 **幾乎不動** 到 **Ludicrous Speed**。越高，切換越頻繁。
- **切換冷卻**（45 秒）：兩次切換之間最短的等待時間。從 **關閉** 到 3 分鐘。
- **切換延遲**（關閉）：ArenaSwap 在換分頁前等多久，讓延遲較大的串流有時間追上。從 **關閉** 到 3 分鐘。
- **比賽間歇再切換**（關閉）：等你要離開的那場比賽進入暫停時段，才執行切換。你可能會錯過切過去那場比賽中的某個片刻。
- **切換通知**（開啟）：每次 ArenaSwap 切換時，發出一則附有比分和原因的通知。
- **比賽結束時**（**保留分頁**）：比賽結束後，那場比賽的分頁會怎麼處理。**從 ArenaSwap 釋放** 會讓分頁維持開啟並取消靜音。**關閉分頁** 會把它關掉。你正在看的分頁，在你離開之前絕不會被動到。
- **掩護頁面**（空白分頁）：老闆鍵會帶你去的地方。它也會把 ArenaSwap 管理的每個分頁靜音，並暫停自動切換。請見[如何使用老闆鍵](/arenaswap/docs/extension/boss-button/)。
- **示範模式**（關閉）：把真實比賽換成預先編排的比賽，讓你不用等真的比賽，也能試用 ArenaSwap。開啟時會出現 **假裝現在是**，它只會改變節日裝飾。

## 評分

- **PowerScore 看重什麼**（經典）：**經典** 看接近的比賽，**一面倒** 看比分懸殊的比賽，**夢幻** 看有你的球員上場的比賽，**自訂** 則為每個聯賽各設一種模式。
- **依聯賽設定模式**（經典）：選了 **自訂** 才會出現。你沒設定的聯賽用經典。
- **PowerScore 信號**（全部開啟）：每種模式衡量的項目。不在意的可以關掉，但至少要保留一個開著。
- **你的球員能為比賽加多少分**（60%）：你的陣容佔多大比重。從 **完全不加** 到 **照完整得分**。
- **你的球員**（空）：最多 50 位讓夢幻追蹤的球員。支援 NFL、NBA、WNBA、MLB 和 NHL。
- **得分規則**（標準得分）：每項數據值多少夢幻得分。
- **收藏球隊加成**（10）：替有你追蹤球隊的比賽加的分數。
- **季後賽加成**（8）：替季後賽加的分數。越後面的輪次加越多。一面倒模式不適用。

更多說明請見[如何改變 ArenaSwap 在比賽中看重什麼](/arenaswap/docs/extension/scoring-modes/)。

## 收藏球隊

- **你關注的球隊**（無）：關注的球隊會固定在列表最上方，它們的比賽也會拿到收藏球隊加成。
- **宿敵**（無）：在一面倒模式下，宿敵慘敗的比賽會排到列表最上方，宿敵領先的比賽則會下沉。其他模式下沒有效果。

## 聯賽

- **已啟用的聯賽**（設定流程中你選的那些）：ArenaSwap 監看的聯賽。多開幾個，它就會在全部之中找出最好看的比賽。
- **大學運動級別與聯盟**：決定哪些大學比賽會出現。選其他級別或聯盟可以擴大或縮小範圍，也可以只看前 25 名。瘋狂三月和大學美式足球季後賽這類冠軍賽輪次一律會顯示，有你收藏球隊的比賽也一樣。

## 顯示

- **顯示即將開賽的比賽**（開啟）：新增一個 即將開賽 區塊，列出尚未開打的比賽，讓你提早指派分頁。
- **提前天數**（7）：即將開賽往後看多遠，範圍 1 到 14 天。
- **保留已結束的比賽**（關閉）：比賽結束後，在 已結束 區塊多保留 24 小時。你可以看數據統計，但不能替它指派分頁。
- **達人技巧**（開啟）：主畫面上的簡短提示。
- **顯示投注與賠率**（關閉）：在比賽卡片和詳細畫面顯示投注盤口。
- **溫度單位**（°F）：比賽詳細畫面上的天氣，用 **°F** 或 **°C**。
- **主題**（深色）：**深色**、**淺色**，或 **跟隨系統**。
- **開場動畫**（開啟）：打開 ArenaSwap 時，每場比賽都有一張對戰海報。
- **節日裝飾**（開啟）：在一年中對的時間出現的雪、彩燈和落葉，聖誕節比賽的襪子，MLB 主場開幕系列賽和季後賽的彩旗，以及 7月4日每次得分時的煙火。每一種都有自己的開關。
- **依聯賽分組比賽**（新安裝為關閉）：把比賽放在各聯賽的標題底下，而不是一份列表。不論開關，你的收藏球隊都固定在最上方。
- **顯示順序**：與 **依聯賽分組比賽** 一起出現。拖曳聯賽，或用箭頭，設定哪個聯賽排最前面。

## Standby Stream

- **啟用 Standby Stream**（關閉）：當你正在看的每場比賽都冷下來時，挑一個備用分頁讓你停靠。
- **低於此分數時待機**（20）：多冷才算冷，範圍 0 到 100。越高，待機越早啟動。
- **待機分頁**（無）：ArenaSwap 帶你去的分頁。

更多說明請見[如何設定 Standby Stream](/arenaswap/docs/extension/standby-stream/)。

## Multiview

僅限 Chrome 和 Edge。請見[如何使用 Multiview](/arenaswap/docs/extension/multiview/)。

- **啟用 Multiview**（關閉）：當你有兩場以上的比賽同時變精彩，就把它們一起顯示在同一個分頁。最精彩的比賽拿到最大的格子，也是唯一有聲音的。開啟時會向瀏覽器要求讀取及變更所有網站的權限。如果你拒絕，Multiview 會維持關閉。
- **精彩度達到**（55）：比賽要多精彩才會加入。越低，Multiview 開得越頻繁。越高，就只留給重大時刻。
- **顯示**（**精彩比賽**）：**精彩比賽** 或 **我的所有比賽**。
- **最多分格數**（4）：同時顯示在螢幕上的比賽數量上限，範圍 2 到 8。

## 個人資料與備份

請見[如何使用個人資料並備份你的設定](/arenaswap/docs/extension/profiles-and-backup/)。

- **個人資料**：可以來回切換的不同設定組合，例如一套給美式足球的週日，一套給三月。可以從目前設定的副本，或從頭開始建立新的。
- **備份或還原**：把你的設定下載成檔案，或匯入一份。匯入可以新增個人資料，也可以取代你目前使用中的那一個的所有設定。
