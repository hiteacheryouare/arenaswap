設定一次 ArenaSwap，開兩場比賽，它就會帶你切到比較好看的那一場。只需要幾分鐘。

## 安裝並選擇聯賽

從 Chrome 線上應用程式商店、Firefox 附加元件或 Edge 外掛商店安裝 ArenaSwap，然後點選工具列上的圖示。一個簡短的設定流程會帶你走完剩下的步驟。

第一個畫面是歡迎頁，點選 **了解**。如果你在另一台電腦用過 ArenaSwap，**有備份檔案嗎？跳過設定，直接匯入** 能把你的設定帶過來。備份檔案的細節請見[設定檔與備份](/arenaswap/docs/extension/profiles-and-backup/)。

在 **你都看哪些運動？** 這一步，勾選你追的聯賽。NBA、NFL、NHL 和 MLB 預設已勾選。每項運動都有 **全部** 核取方塊，想一次選整組就用它。點選 **下一步**。這份清單隨時能在設定裡更改。

## 收藏你的球隊

在 **選擇你的球隊** 這一步，點一下球隊就能加上星號。加星號的球隊在 ArenaSwap 挑選比賽時會得到加分，所以它們的比賽更容易觸發切換。細節請見[收藏球隊](/arenaswap/docs/extension/favorite-teams/)。

點選 **完成**。還不想選的話，點 **跳過**。

接著會看到 **一切就緒！** 點選 **開始導覽** 快速走一遍，或點 **直接開始**。之後想重看導覽，按頂端的 **?** 按鈕。

## 開兩場直播

在兩個獨立的瀏覽器分頁各開一場比賽，用你平常看球的平台就行。現在沒有兩場直播比賽？開啟[示範模式](/arenaswap/docs/extension/demo-mode/)，用它預先編排的比賽。

## 把每個分頁連到它的比賽

打開 ArenaSwap 的彈出視窗。在每場比賽的卡片上，用 **指派分頁** 下拉選單，選出你為那場比賽開的分頁。

串流已經開好了？畫面上可能會跳出 **這些分頁看起來像比賽** 的橫幅，提議幫你配對。點選 **查看** 檢視它的猜測。

<Demo name='popup' tabs />

連好的比賽會移到列表最上方的 **活躍分頁**。ArenaSwap 只會在你連好的分頁之間切換。

## 看它切換

兩個分頁都開著，照常看球。當另一場變得更精彩，ArenaSwap 會帶你過去、取消它的靜音，並把你離開的那個分頁靜音。開著 **切換通知**（預設就是開的）時，你還會收到一則簡短的訊息，說明發生了什麼事、為什麼切換。
