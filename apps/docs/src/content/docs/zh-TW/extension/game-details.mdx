點任何一場比賽，就能看到它為什麼排在這個位置，以及它的看點在哪。

## 打開一場比賽

在彈出視窗點比賽卡片。在[節目表](/arenaswap/docs/extension/guide/)裡，點比賽的長條，它會在側邊面板開啟。點 **返回** 回到列表，在節目表則點 **關閉**。

比分下方有一排分頁：**總覽** 一定會有，**對戰** 在比賽開始前出現，**數據統計** 在比賽開打後出現，聯賽有排名表時則會有 **排名**。放不下的會收進 **更多**。

## 看看比賽為什麼排這麼前面

打開一場進行中的比賽，看 **總覽** 上的 **PowerScore 詳細分析**。它會顯示是什麼讓這場比賽值得看：

- **接近度**：比分咬得多緊。
- **關鍵時刻**：離比賽結束多近，而且勝負還沒定。
- **氣勢**：是否有一隊正在打一波攻勢。
- **領先交替**：最近領先的一方換了幾次。
- **逆轉**：落後的一方是否正在追上來。

每一項都會顯示它的分數，接著是各種加成（額外加分，例如你收藏的球隊）和扣分（扣掉分數，例如廣告時段），最後是 **最終 PowerScore**。總分下面那一行會說明現在是什麼在推動它。

<Demo name='breakdown' />

遇到 **中場休息**、**節間休息** 或比賽延遲而暫停的比賽，在恢復比賽前會顯示 0。已經結束的比賽不會有 PowerScore。想改變計分看重什麼，請見[計分模式](/arenaswap/docs/extension/scoring-modes/)。

## 追蹤比賽進展

比賽進行時，詳細分析下方的圖表會逐漸填滿。**PowerScore 走勢** 顯示比賽從什麼時候開始變好看，**勝率** 顯示勝負的天平怎麼擺盪。還有比分和分差的圖表。

<Demo name='charts' />

進行中的比賽會依運動項目多出更多資訊。**最新戰況** 顯示剛剛發生了什麼，棒球還有 **後續打者**，顯示接下來上場打擊的是誰。美式足球顯示進攻檔數與碼數，籃球顯示暫停與犯規罰球。季後賽則顯示系列賽比數。

## 開賽前做好準備

尚未開打的比賽會有一張 **準備開球** 卡片（依運動不同，可能是跳球、開球或第一球投出）。在這裡可以加上比賽加成，在彈出視窗還能挑要用哪個分頁開這場比賽。

再往下，視項目而定會有 **先發投手** 或 **先發守門員**，接著是 **主力球員**，以及 **對戰** 分頁裡的 **近期戰績**、**球季數據** 和 **傷兵**。想追蹤某支球隊，點隊徽旁的星號。這個動作的作用，請見[收藏球隊](/arenaswap/docs/extension/favorite-teams/)。

## 查看數據統計與排名

**數據統計** 有逐節比分、球隊數據，以及你正在看的那項運動的球員成績。**排名** 顯示聯賽排名表，這兩支球隊會被標示出來。

## 找到在哪裡看

**比賽資訊** 列出頻道或平台、場館和天氣。已結束的比賽還會顯示觀眾人數。尚未開賽的比賽可以連到 **門票**。

只有在設定裡開啟 **顯示投注與賠率**，才會顯示投注盤口。

## 加上比賽加成

想讓某場比賽不管比分如何都出現在螢幕上？**比賽加成** 會替它的 PowerScore 加分，讓 ArenaSwap 更常選它。輸入 0 到 100 的數字，輸入 0 就會移除。

<Demo name='game-boost' />

比賽加成欄位出現在進行中和尚未開賽的比賽上。它是唯一能把 PowerScore 推到 100 以上的東西，詳細分析會把它顯示成「比賽加成」。
