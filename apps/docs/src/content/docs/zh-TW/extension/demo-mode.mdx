示範模式提供練習比賽，沒有真的比賽時，也能看 ArenaSwap 切換分頁。休賽期，或是想先試試再放心交給瀏覽器，都很好用。

## 開啟

1. 打開設定，選擇 **切換**。
2. 在 **示範** 底下，開啟 **示範模式**。

比賽列表會出現來自多個聯賽的練習比賽。不管那些聯賽有沒有開啟，它們都會顯示，比分也會持續變動。有的會慢慢拉開差距，有的會上演逆轉。

## 試一次切換

幫兩三場示範比賽指派分頁，做法跟真的比賽一樣。比賽變精彩時，ArenaSwap 會切換分頁、靜音或取消靜音。步驟請見[同時觀看多場比賽](/arenaswap/docs/extension/watching-multiple-games/)。

這也是試玩[如何控制 ArenaSwap 切換分頁的時機](/arenaswap/docs/extension/switching-and-sensitivity/)裡那些滑桿的好時機，調整後馬上就能看到效果。

開啟示範模式後會出現 **假裝現在是**，它只會改變節慶裝飾。

## 關閉

把 **示範模式** 切回關閉。練習比賽會消失，你的真實比賽會回來。
