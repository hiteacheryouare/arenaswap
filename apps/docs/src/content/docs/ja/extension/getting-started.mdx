ArenaSwap は一度設定して、試合を2つ開くだけ。あとは面白いほうへ移動してくれます。所要時間は数分です。

## インストールしてリーグを選ぶ

Chrome ウェブストア、Firefox アドオン、Edge アドオンのいずれかから ArenaSwap を追加し、ツールバーのアイコンをクリックします。残りは短いセットアップが案内してくれます。

最初の画面はウェルカム画面です。**了解**をクリックします。別のパソコンで ArenaSwap を使ったことがあるなら、**バックアップファイルがありますか？設定をスキップして読み込む**で設定を引き継げます。ファイルについては[プロフィールとバックアップ](/arenaswap/docs/extension/profiles-and-backup/)をご覧ください。

**どのスポーツを観ますか？**で、追いかけているリーグにチェックを入れます。最初は NBA、NFL、NHL、MLB にチェックが入っています。各スポーツには、グループ全体を選べる**すべて**のチェックボックスもあります。**次へ**をクリックします。このリストは、設定からいつでも変更できます。

## チームにスターを付ける

**チームを選ぶ**で、チームをタップしてスターを付けます。スターを付けたチームは試合の選定で加点されるので、その試合が切り替えで選ばれやすくなります。詳しくは[お気に入りチーム](/arenaswap/docs/extension/favorite-teams/)をご覧ください。

**完了**をクリックします。まだ選びたくなければ**スキップ**です。

**準備完了！**の画面に進みます。簡単な案内を見るなら**ツアーを開始**、すぐ始めるなら**すぐに始める**をクリックします。ツアーは、あとから上部の**?**ボタンでもう一度見られます。

## ライブ試合を2つ開く

ふだん観ている配信先で、2つの試合を別々のブラウザタブで開始します。いまライブ中の試合が2つない？[デモモード](/arenaswap/docs/extension/demo-mode/)をオンにして、台本つきの試合を使いましょう。

## タブと試合を紐づける

ArenaSwap のポップアップを開きます。各試合のカードにある**タブを割り当て**のドロップダウンで、その試合用に開いたタブを選びます。

すでに配信を開いているなら、**これらのタブ、試合っぽいです**というバナーが、組み合わせを提案してくれることがあります。**見てみる**をクリックして、提案内容を確認しましょう。

<Demo name='popup' tabs />

紐づけた試合は、リストの先頭にある**アクティブタブ**に上がります。ArenaSwap が切り替えるのは、紐づけたタブの間だけです。

## 切り替わるのを見る

2つのタブを開いたまま、試合を観ます。もう一方が盛り上がってくると、ArenaSwap がそちらへ移動してミュートを解除し、離れたタブをミュートします。**切り替え通知**がオン（初期設定です）なら、何が起きたのか、なぜ切り替えたのかを伝える短い通知も届きます。
