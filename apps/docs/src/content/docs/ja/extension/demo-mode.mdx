デモモードは練習用の試合を用意するので、本物の試合がない日でも ArenaSwap のタブ切り替えを確かめられます。オフシーズンや、大事なブラウザを任せる前にお試ししたいときに便利です。

## オンにする

1. 設定を開いて**切り替え**を選びます。
2. **デモ**の下にある**デモモード**をオンにします。

ゲームリストに、複数のリーグの練習用の試合が並びます。そのリーグがオンかどうかに関係なく表示され、スコアも動き続けます。リードを広げる試合もあれば、逆転劇を演じる試合もあります。

<Demo name='toggle' setting='setup.demoMode' />

## 切り替えを試す

本物の試合のときと同じように、2、3 試合のデモにタブを割り当てます。試合が盛り上がるにつれて、ArenaSwap がタブを切り替え、ミュートしたり解除したりします。手順は[複数の試合を同時に観戦する方法](/arenaswap/docs/extension/watching-multiple-games/)にあります。

[ArenaSwap のタブ切り替えタイミングを調整する方法](/arenaswap/docs/extension/switching-and-sensitivity/)のスライダーを試すのにも向いています。動きの違いがすぐ分かります。

**日付をこう見なす**は、デモモードがオンのときだけ表示されます。変わるのはホリデー装飾だけです。

## オフにする

**デモモード**をオフに戻します。練習用の試合は消えて、本物の試合が戻ってきます。
