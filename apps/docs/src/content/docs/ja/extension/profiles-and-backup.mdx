プレーオフの夜と、ファンタジーフットボールの日曜日では、ほしい設定が違います。プロフィールなら両方を保存して、ワンクリックで切り替えられます。バックアップを使えば、設定を別のブラウザに持っていけます。

## プロフィールを作る

最初は誰でもプロフィールが1つあり、名前は **main** です。

1. 設定を開き、**プロフィールとバックアップ**を選びます。
2. **新しいプロフィール**をクリックして名前を入力します。
3. いまの設定から始めるなら**mainをコピー**を、初期設定から始めるなら**ゼロから始める**をクリックします。（ボタンには、現在のプロフィールの名前が入ります。）

同じ名前のプロフィールは2つ作れません。プロフィールには、設定とファンタジーのロスターが入ります。新しく作ったプロフィールが、現在のプロフィールになります。

## プロフィールを切り替える

**プロフィール**のリストで、プロフィールの名前をクリックします。使用中のものにはチェックマークが付きます。リーグ、お気に入りチーム、スコアリングモードがすぐに切り替わります。

## 名前変更、エクスポート、削除

プロフィールの横の3つの点をクリックします。

- **名前を変更**で、新しい名前を付けられます。
- **エクスポート**は、そのプロフィールを保存できる状態でバックアップページを開きます。
- **削除**は、プロフィールを設定とファンタジーのロスターごと削除します。コピーを残したいなら、先にエクスポートしてください。

使用中のプロフィールは削除できません。先に別のプロフィールへ切り替えてください。

## 設定を同期する

**ブラウザと同期されるもの**の下に、現在のプロフィールの内容として、オンのリーグ、お気に入りチーム、スコアリングモード、ファンタジーのロスターが一覧になります。ブラウザの同期がオンなら、これらはすべて別のパソコンにも引き継がれます。それ以外のプロフィールは同期されません。

## バックアップを保存する

1. **バックアップまたは復元…**をクリックします。新しいタブで開きます。
2. プロフィールが複数あるときは、**プロフィール**メニューから1つ選びます。
3. **バックアップをダウンロード**をクリックします。

ファイル名には、プロフィール名と今日の日付が入ります。たとえば `arenaswap-settings-main-2026-11-03.json` のようになります。

## バックアップを使う

移行先のブラウザで**バックアップまたは復元…**を開きます。まだ初回セットアップの途中なら、**バックアップファイルがありますか？設定をスキップして読み込む**をクリックします。

1. ファイルを**バックアップをここにドロップ**にドロップするか、**ファイルを選ぶ**をクリックします。
2. ファイルの設定と、いまの設定を見比べます。
3. どちらかを選びます。
   - **新しいプロフィールとして追加**は、いまの設定をすべて残したまま、ファイルの設定を横に追加します。
   - **（プロフィール名）を置き換える**は、現在のプロフィールの設定をすべて、ファイルの設定に入れ替えます。バックアップがデモモードで取られたものだった場合は、デモモードに戻ります。
4. 「お引っ越し完了です」と表示されたら、**タブを閉じる**をクリックします。

ファイルを間違えた？**別のファイルを選ぶ**で最初からやり直せます。

うまくいかないときは、次を確認してください。

- 「…そのファイルを光にかざしてみましたが、1語も読み取れませんでした」: ファイルが壊れています。バックアップを取り直してください。
- 「ファイル自体はまったく問題ありませんが、うちのものではありません」: ArenaSwap のファイルではありません。自分で保存したものを選んでください。
- 「このファイルはより新しい ArenaSwap で作られています」: 拡張機能を更新して、もう一度試してください。
- 「保存できませんでした」: もう一度試してください。
