Multiview は盛り上がっている試合を1つの画面に並べるので、どれを観るか選ばなくて済みます。いちばん盛り上がっている試合が最大のボックスと音声を手に入れます。

対応しているのは Chrome と Edge です。Firefox には Multiview がありません。

## オンにする

1. 設定を開いて **Multiview** を選びます。
2. **Multiviewを有効にする**をオンにします。
3. 短いガイドで流れを説明します。**次へ**、**続ける**の順にクリックします。
4. ブラウザが、ArenaSwap に「すべてのウェブサイト上にある自分の全データの読み取りと変更」を許可するか尋ねます。許可してください。これで、複数の配信が1つのタブにまとまります。

**今はしない**をクリックするか、ブラウザで許可しないと、Multiview はオフのままです。ほかの機能は変わらず使えます。

## 試合ごとにタブを割り当てる

試合ごとに配信を専用のタブで開き、その試合のカードにある**タブを割り当て**のドロップダウンでそのタブを選びます。手順は[複数の試合を同時に観戦する方法](/arenaswap/docs/extension/watching-multiple-games/)にあります。

**自動切り替えを有効にする**はオンのままにしてください。オフにすると Multiview は閉じます。

## 開くタイミングを選ぶ

**Multiview** にある3つの設定で決まります。

- **盛り上がり度**は、試合が「盛り上がっている」と数えられるのに必要な PowerScore で、0〜100の範囲です。初期値は55です。**開きやすく**側に動かすと Multiview が増え、**大一番のみ**側に動かすと減ります。
- **表示する試合**は、どの試合にボックスを割り当てるかを選びます。**盛り上がっている試合**は、スコアが設定値以上の試合だけを表示します。**自分のすべての試合**は、タブを割り当てたすべての試合を表示します。
- **ボックスの最大数**は、同時に表示する試合数の上限で、2〜8の範囲です。初期値は4です。それ以上の試合が条件を満たしたら、PowerScore の高い順にボックスが割り当てられます。

Multiview は、あなたの試合のうち2つ以上が**盛り上がり度**のスコアに達すると開きます。ほかの切り替えと同じく、**切り替えクールダウン**と**切り替え遅延**にも従います。どちらも[ArenaSwap のタブ切り替えタイミングを調整する方法](/arenaswap/docs/extension/switching-and-sensitivity/)で説明しています。

1試合が盛り上がっていて、もう1試合が**盛り上がり度**のスコアまで10ポイント以内に迫ると、ミュートされた Multiview タブがタブの並びの末尾に開き、それらの試合の読み込みを始めます。2試合目が下がっても、また上がってくるかもしれないので、タブは2分間残ります。そのタブを閉じると、Multiview は切り替えクールダウンが明けるのを待ってから、もう一度試みます。

## 開いている間

ArenaSwap は Multiview タブを、いまの試合のタブの隣に移動する（または、そこに新しく開く）と、そのタブへ移動します。通知がオンなら、**切り替え → Multiview** の通知が届きます。

左上のいちばん大きいボックスはいちばん盛り上がっている試合のもので、音が出るのもそこだけです。ほかの試合はその周りに並びます。試合のタブは、バックグラウンドでミュートされたまま開いています。

## 閉じるとき

Multiview は一度開くと、少なくとも切り替えクールダウンの間、そして配信のどれかが再生を始めるまで開いたままです。

盛り上がっている試合が1つだけになると、その試合が2分間 Multiview タブいっぱいに表示されます。その間にほかの試合がまた盛り上がると、すべてのボックスが戻ります。戻らなければ、ArenaSwap はその試合自身のタブへ移動して Multiview を閉じます。もう1つの試合が終わった場合や、ボックスのない自分の試合が切り替え先になるほど大きくリードした場合は、2分を待ちません。

試合は、CM 中もボックスを保ちます。

Multiview タブを自分で閉じると、切り替えクールダウンが明けたあとに、また開くことがあります。別のウェブページに移動すると Multiview は止まり、10分間はそれらの試合を開き直しません。

1分たっても配信が1つも再生されない場合は、ArenaSwap がベストの試合へ戻し、10分後にもう一度試みます。あるボックスだけがずっと再生されないときは、その配信を専用のタブで開き、そこで再生されるか確かめてください。
