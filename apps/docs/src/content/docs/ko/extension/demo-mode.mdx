데모 모드는 연습 경기를 보여 줘서, 진짜 경기가 없을 때도 ArenaSwap이 탭을 전환하는 모습을 볼 수 있게 해 줘요. 비시즌이나, 브라우저를 맡기기 전에 먼저 써 보고 싶을 때 편해요.

## 켜기

1. 설정을 열고 **전환**을 선택하세요.
2. **데모** 아래에서 **데모 모드**를 켜세요.

경기 목록이 여러 리그의 연습 경기로 채워져요. 해당 리그를 켜 놨는지와 상관없이 나타나고, 점수도 계속 움직여요. 리드를 벌려 가는 경기도 있고, 역전극을 펼치는 경기도 있어요.

<Demo name='toggle' setting='setup.demoMode' />

## 전환 해 보기

실제 경기처럼 데모 경기 두세 개에 탭을 할당하세요. 경기가 달아오르면 ArenaSwap이 탭을 전환하고, 음소거하고, 음소거를 풀어 줘요. 방법은 [여러 경기 보기](/arenaswap/docs/extension/watching-multiple-games/)에 나와 있어요.

[ArenaSwap이 탭을 전환하는 시점 조절하기](/arenaswap/docs/extension/switching-and-sensitivity/)의 슬라이더를 시험해 보기에도 좋아요. 바로 어떻게 달라지는지 보여요.

**날짜를 이렇게 간주**는 데모 모드를 켜면 나타나요. 홀리데이 장식만 바꿔 줘요.

## 끄기

**데모 모드**를 다시 끄면 연습 경기는 사라지고 실제 경기가 돌아와요.

## 관련 문서

- 아직 설정 전이라면 [ArenaSwap 시작하기](/arenaswap/docs/extension/getting-started/)부터 보세요.
- [ArenaSwap이 탭을 전환하는 시점 조절하기](/arenaswap/docs/extension/switching-and-sensitivity/)에서 여기서 시험해 볼 만한 설정을 다뤄요.
