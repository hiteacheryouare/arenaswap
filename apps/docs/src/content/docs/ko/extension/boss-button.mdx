누가 옆을 지나가는데, 연장전이 가득한 탭을 보고 있으면 곤란하죠. 보스 버튼은 경기를 한 번에 숨겨 줘요.

## 하는 일

누르면 ArenaSwap이 이렇게 해요.

- 경기 탭을 음소거해요.
- 자동 전환을 멈춰요. 알아서 경기로 끌려가는 일이 없어요.
- 위장 페이지로 이동해요.

## 누르는 방법

- 팝업 상단 바의 시크릿 아이콘을 클릭하세요.
- 아니면 아무 탭에서나 **Alt+Shift+X**를 누르세요. 팝업을 먼저 열 필요 없어요.

## 위장 페이지 정하기

설정을 열고 **전환**에서 **위장 페이지**를 찾으세요. 스프레드시트나 문서처럼 바빠 보이는 웹 주소를 입력하면 돼요. Enter를 누르거나 입력란 밖을 클릭하면 저장돼요.

- 그 페이지가 이미 열려 있으면 보스 버튼이 그 탭으로 이동해요.
- 열려 있지 않으면 ArenaSwap이 새로 열어 줘요.
- 입력란을 비워 두면 빈 탭이 열려요.
- 웹 주소만 가능해요. 다른 건 "웹 주소가 아닌 것 같아요."라고 떠요.

## 경기 되돌리기

보스 버튼은 스스로 되돌아가지 않아요. 상황이 정리되면 팝업을 열고 **자동 전환 활성화**를 다시 켜세요. 탭과 경기 할당은 그대로 있어요.

## 단축키 바꾸기

브라우저의 확장 프로그램 단축키 페이지에서 **상사가 온다**에 새 키를 지정하세요.

- Chrome: `chrome://extensions/shortcuts`
- Edge: `edge://extensions/shortcuts`
- Firefox: 부가 기능 관리자, 톱니바퀴 메뉴, **확장 기능 단축키 관리** 순서로 들어가세요.

다른 확장 프로그램이 이미 Alt+Shift+X를 쓰고 있으면 거기서 다른 키를 고르세요. 단축키가 없어도 버튼 클릭으로는 그대로 작동해요.

## 관련 문서
