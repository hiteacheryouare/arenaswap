플레이오프 날 밤과 판타지 풋볼 일요일은 설정이 달라야 해요. 프로필이 있으면 둘 다 두고 한 번에 바꿀 수 있어요. 백업은 설정을 다른 브라우저로 가져가게 해 줘요.

## 프로필 만들기

처음에는 모두 프로필 하나, **main**으로 시작해요.

1. 설정을 열고 **프로필 및 백업**을 선택하세요.
2. **새 프로필**을 클릭하고 이름을 입력하세요.
3. 지금 설정에서 시작하려면 **main 복사**를, 기본값으로 시작하려면 **처음부터 시작**을 클릭하세요. (이 버튼에는 현재 프로필 이름이 들어가요.)

프로필 두 개가 같은 이름을 쓸 수는 없어요. 프로필에는 설정과 판타지 로스터가 들어 있어요. 새 프로필이 현재 프로필이 돼요.

## 프로필 바꾸기

**프로필** 목록에서 프로필 이름을 클릭하세요. 쓰고 있는 프로필에는 체크 표시가 붙어요. 리그, 응원팀, 점수 모드가 바로 바뀌어요.

## 이름 변경, 내보내기, 삭제

프로필 옆의 점 세 개를 클릭하세요.

- **이름 변경**으로 새 이름을 정해요.
- **내보내기**는 그 프로필이 저장 준비된 백업 페이지를 열어요.
- **삭제**는 프로필을 설정, 판타지 로스터와 함께 지워요. 사본이 필요하면 먼저 내보내세요.

쓰고 있는 프로필은 삭제할 수 없어요. 먼저 다른 프로필로 바꾸세요.

## 설정 동기화하기

**브라우저와 동기화돼요** 아래에 현재 프로필이 담고 있는 항목이 나와요. 켜 놓은 리그, 응원팀, 점수 모드, 판타지 로스터예요. 브라우저에서 동기화를 켜 놓으면 이 항목들이 다른 컴퓨터로 따라가요. 다른 프로필은 그대로 남아요.

## 백업 저장하기

1. **백업 또는 복원…**을 클릭하세요. 새 탭에서 열려요.
2. 프로필이 둘 이상이면 **프로필** 메뉴에서 하나를 고르세요.
3. **백업 다운로드**를 클릭하세요.

파일 이름에 프로필 이름과 오늘 날짜가 들어가요. 예를 들면 `arenaswap-settings-main-2026-11-03.json`이에요.

## 백업 사용하기

옮겨 갈 브라우저에서 **백업 또는 복원…**을 여세요. 아직 처음 설정 중이라면 **백업 파일이 있나요? 설정을 건너뛰고 가져오기**를 클릭하세요.

1. 파일을 **여기에 백업을 놓으세요** 위에 놓거나 **파일 고르기**를 클릭하세요.
2. 파일의 설정과 내 설정을 비교하세요.
3. 하나를 고르세요.
   - **새 프로필로 추가**는 지금 가진 걸 모두 두고 파일의 설정을 나란히 추가해요.
   - **바꾸기**는 현재 프로필의 모든 설정을 파일의 설정으로 바꿔요. 백업이 데모 모드에서 만들어졌다면 데모 모드로 돌아가요.
4. "이사가 모두 끝났어요"가 보이면 **탭 닫기**를 클릭하세요.

파일을 잘못 골랐나요? **다른 파일 고르기**를 누르면 처음부터 다시 해요.

문제가 생기면 이렇게 하세요.

- "저희 정보원이 그 파일을 불빛에 비춰 봤지만 한 글자도 알아보지 못했어요": 파일이 손상됐어요. 새 백업을 저장하세요.
- "파일 자체는 멀쩡하지만 저희 것은 아니에요": ArenaSwap에서 만든 파일이 아니에요. 직접 저장한 파일을 고르세요.
- "이 파일은 더 새로운 ArenaSwap에서 만들어졌어요": 확장 프로그램을 업데이트한 뒤 다시 해 보세요.
- "저장하지 못했어요": 다시 해 보세요.

## 관련 문서

- [ArenaSwap 설정 레퍼런스](/arenaswap/docs/extension/settings/)에 프로필과 백업 또는 복원 설정이 나와 있어요.
- [ArenaSwap 시작하기](/arenaswap/docs/extension/getting-started/)에서 처음 설정을 다뤄요.
