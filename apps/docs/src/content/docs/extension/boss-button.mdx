Somebody walks past, and a tab full of overtime is the wrong thing to be looking at. The boss button hides the games in one move.

## What it does

Press it and ArenaSwap:

- Mutes your game tabs.
- Pauses auto-switching, so nothing pulls you back to a game on its own.
- Takes you to your decoy page.

<Demo name='boss-button' />

## Press it

- Click the incognito icon in the popup's top bar.
- Or press **Alt+Shift+X** from any tab. You don't need to open the popup first.

## Pick your decoy page

Open Settings, then **Switching**, and find **Decoy page**. Type any web address that looks busy, like a spreadsheet or a doc. Press Enter or click out of the box to save.

- If the page is already open, the boss button jumps to that tab.
- If it isn't, ArenaSwap opens it for you.
- Leave the box empty and you get a blank tab.
- Only web addresses work. Anything else shows "That doesn't look like a web address."

## Get the games back

The boss button doesn't undo itself. When the coast is clear, open the popup and turn **Enable auto-switching** back on. Your tabs and game assignments are still there.

## Change the shortcut

Set a new key for **Boss is coming** on your browser's extension shortcuts page:

- Chrome: `chrome://extensions/shortcuts`
- Edge: `edge://extensions/shortcuts`
- Firefox: Add-ons Manager, the gear menu, then **Manage Extension Shortcuts**

If another extension already uses Alt+Shift+X, pick a different key there. With no shortcut set, the button still works by clicking.
