Watching several games at once used to mean a wall of muted tabs and constant alt-tabbing to check scores. ArenaSwap needs only one rule: open a stream, tell it which game that stream is, and let it handle the rest.

## Open each stream in its own tab

Start each game the way you already do, in whatever tab and on whatever service you stream it from. ESPN+, Peacock, YouTube TV, your cable provider's site, a free league stream, it doesn't matter. ArenaSwap only cares that the stream lives in its own browser tab.

## Assign a tab to each game

In the ArenaSwap popup, find the card for each game. Use its **— Assign a tab —** dropdown to pick the tab you opened for that game. The same dropdown appears on a game's pre-game card, so you can assign a tab before the game even starts.

If a tab is already assigned to another game, its dropdown entry is grayed out and marked **(in use)**. To reassign that tab, unassign it from the other game first.

## Watch the list sort itself

Once you've assigned at least one tab, the main screen splits into sections:

- **Active Tabs** holds every live game with an assigned tab, sorted by PowerScore. Your starred teams' games pin to the top of their league section.
- **Live Games** holds everything else live in your enabled leagues, in the same order, in case something there is worth grabbing a tab for.
- **Up Next** holds upcoming games in your enabled leagues, grouped by date.

## Let ArenaSwap manage the tabs

With more than one tab assigned, ArenaSwap takes over deciding which one is active. It mutes every tab you've registered except the one currently in focus. It switches focus to whichever registered game has the highest PowerScore, once that game pulls far enough ahead. You never have to click into a tab to check on it or reach for the mute button yourself.

If you want to stop ArenaSwap from touching a specific tab, unassign it from the dropdown. If you want to stop it from switching anything at all, turn off **Enable auto-switching** in the top bar.
